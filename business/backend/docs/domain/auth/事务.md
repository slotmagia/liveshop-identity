# 登录验证码事务

| 用例 | 同一事务 | 事务外 |
|---|---|---|
| 请求验证码 | 锁定活动店铺、拒绝冷却期内的同目的地重发、过期同目的地旧 PENDING、插入散列与 `expires_at` | SYNC `Dispatch`；失败不删除行 |
| 核验验证码 | 按 challengeId 锁定、校验店铺与 TTL、比较散列、推进 CONSUMED/EXPIRED | 无 Platform 调用；不签发会话 |
| 兑现已核验挑战登录 | 锁定 CONSUMED 挑战、查找或创建 SHOP 凭据、同店游客归属迁移或撤销、插入 CUSTOMER session/refresh、绑定 `login_session_id`、Outbox | Access Identity 与 cookie 只在提交后签发；挑战不可再兑现 |

隔离级别 `REPEATABLE READ`。非幂等外部调用不进事务。
