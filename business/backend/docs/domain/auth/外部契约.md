# 登录验证码外部契约

| 操作 | 鉴权 | 说明 |
|---|---|---|
| `POST /shop/identity/login/otp` | `public` + `X-Liveshop-Surface: shop` | `{shopCode,phone?,email?}`；至少一种目的地。成功 `{challengeId,ttlSeconds,expiresAt}` |
| `POST /shop/identity/login` | 同上 | `{shopCode,challengeId,code}`；成功 `{challengeId,verified}`；不签发会话 |
| `POST /auth/login` | Shop/Live surface；CUSTOMER | 密码路径 `{realm,username,password,shopCode}`；验证码路径 `{realm,shopCode,challengeId}`（互斥）。已核验挑战兑现为 CUSTOMER 会话，可升级当前游客 |
| Platform `Dispatch` | Identity workload mTLS | `eventKey=identity.auth.otp.requested`；recipients 为请求中的 phone/email |

浏览器不得调用 Platform Dispatch。发送失败对用户只暴露领域错误，不暴露通道驱动细节。
