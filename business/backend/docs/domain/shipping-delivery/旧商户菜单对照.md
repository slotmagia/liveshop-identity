# 商户后台「发货/配送」迁移对照

## 旧页面与接口证据

- 菜单：`menu.settings_shipping`，路由 `/settings/shipping-delivery`。
- 代码入口：`woklive-merchant/src/views/business/settings/module`。
- 交互：加载配送规则；CRUD 运费模板；维护发货预设（发货地、商品范围、分区费率）；启停预设。
- 旧接口：`/commercial/settings/shipping*`、`/commercial/settings/shipping-presets*`，绑定商户 JWT 当前店铺。

## 字段与范围映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `appid + commercial_id` | `merchant_id + shop_id` | `merchant_id` 只从 merch Session 读取；`shop_id` 为会话店或本商户店铺选择。 |
| `POST .../save`（有 id 则更新） | `POST` 创建 / `PUT` 更新 | 拆成封闭集合动词；写入带 `commandKey` 与版本。 |
| `POST .../delete`、`DELETE .../{id}` | `POST .../retire` | 物理删除改为 `RETIRED` 终态。 |
| `POST .../{id}/status` | `enable` / `disable` | 禁止 path 末段 `status`。 |
| 行上平台状态 | 治理叠加层 `module=shipping` | 只读展示；受限时禁止写入。 |

## 页面迁移结果

- 菜单目录、名称和 `/settings/shipping-delivery` 保持不变。
- Contribution `identity.merch.settings-shipping-delivery` 替换占位 `identity.placeholder.merch.settings-shipping-delivery`。
- 不迁「物流发货」`/logistics`（发货单/轨迹），那是另一菜单。
