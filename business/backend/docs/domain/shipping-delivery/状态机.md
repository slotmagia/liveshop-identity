# 发货/配送状态机

配送规则与发货预设共用商户状态：

```text
ACTIVE ──disable──> DISABLED
DISABLED ──enable──> ACTIVE
ACTIVE|DISABLED ──retire──> RETIRED
RETIRED ──任何命令──> 拒绝
```

| 转换 | 前置条件 | 副作用 | 幂等 |
|---|---|---|---|
| 创建 | 店铺未关闭；叠加层 `active` | 插入 `ACTIVE`（或请求声明的 `DISABLED`），`version=1` | 同 `commandKey` 重放创建结果 |
| 编辑 | 当前版本匹配；非 `RETIRED`；叠加层 `active` | 更新字段，`version+1` | 同键同摘要重放 |
| `ACTIVE → DISABLED` / `DISABLED → ACTIVE` | 仅发货预设；当前版本匹配；叠加层 `active` | 只改状态，`version+1` | 同键同摘要重放 |
| `ACTIVE/DISABLED → RETIRED` | 当前版本匹配；叠加层 `active` | 状态终态；若该预设是默认则取消默认 | 同键同摘要重放已退役结果 |

配送规则没有独立 enable/disable 命令；编辑时直接写 `ACTIVE`/`DISABLED`。旧 `POST /shipping/delete` 与 `DELETE /shipping-presets/{id}` 映射为 `retire`，不再物理删除。
