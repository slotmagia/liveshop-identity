# 发货/配送事务边界

| 用例 | 同一事务内必须完成 | 失败恢复 |
|---|---|---|
| 创建/更新配送规则 | 写入/锁定命令键、锁定未关闭店铺、条件插入或按版本更新、保存完整响应 | 任一步失败整笔回滚；相同 key 重放既有结果 |
| 退役配送规则 | 命令键、锁定规则与店铺、校验版本、推进 `RETIRED` | 提交未知时用原 key 重试 |
| 创建/更新发货预设 | 命令键、锁定店铺、规范化分区 JSON、取消其它默认、条件写入 | 默认槽在同一事务切换；唯一键或版本冲突不留下命令账本完成态 |
| 启停发货预设 | 命令键、锁定预设、校验版本与非退役、更新状态 | 同键同摘要重放 |
| 退役发货预设 | 命令键、锁定预设、推进 `RETIRED` 并清除默认标记 | 终态可重放，不能恢复 |

叠加层读取发生在写事务之前的 merch 逻辑层；仓储只校验店铺未关闭。不发布 Outbox。事务隔离使用 `REPEATABLE READ`。
