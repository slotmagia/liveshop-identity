# 发货/配送业务不变量

1. 每条配送规则和发货预设必须绑定同一 `identity_shop` 行证明的 `merchant_id + shop_id`。`app_id`/`commercial_id` 不是运行时标识。浏览器不得提交或改写 `merchantId`。
2. 平台叠加层只存在于 `identity_merchant_capability`（`module=shipping`）。规则行和预设行不得复制 `platform_status`。叠加层非 `active` 时禁止一切写入，包括启停和退役。
3. 运费与满额包邮以分为单位且非负；`min_days ≤ max_days`，天数不超过 365。
4. 发货预设 `product_scope=ALL` 时 `product_ids` 必须为空；`SELECTED` 时至少一件，且 id `> 0`。商品 id 是 Catalog 引用，Identity 不校验商品是否存在。
5. 同一店铺未退役预设中最多一条 `is_default=true`。将另一条设为默认时，必须在同一事务取消旧默认。
6. 每个预设至少一个分区；每个分区至少一个地区和一条费率。国家码为大写两字母。费率 `transit_type` 只能是 `STANDARD` / `EXPRESS` / `ECONOMY`。免费费率 `price_fen` 必须为 0。
7. 更新、启停和退役必须携带当前 `expected_version`。同一 `command_key` 重放返回第一次已提交结果；不同摘要复用该 key 必须冲突。
8. `RETIRED` 是终态。退役后事实行保留，默认列表不再返回；不得恢复同一行。
