# 商户发货/配送对外契约

商户后台页面继续使用菜单路由 `/settings/shipping-delivery`。经 Gateway 调用以下唯一主契约。`merchantId` 只来自 merch Module Session；浏览器提交 `shopId`。会话已绑定店铺时不得改店。

| 方法与路径 | 用途 | 幂等 | 权限 |
|---|---|---|---|
| `GET /merch/identity/shipping-delivery/shops` | 当前商户未关闭店铺目录 | safe | `identity.shipping.read` |
| `GET /merch/identity/shipping-delivery/rules` | 分页列出本店未退役配送规则 | safe | `identity.shipping.read` |
| `POST /merch/identity/shipping-delivery/rules` | 创建配送规则 | `commandKey` | `identity.shipping.manage` |
| `PUT /merch/identity/shipping-delivery/rules/{ruleId}` | 按版本编辑 | `commandKey` | `identity.shipping.manage` |
| `POST /merch/identity/shipping-delivery/rules/{ruleId}/retire` | 退役配送规则 | `commandKey` | `identity.shipping.manage` |
| `GET /merch/identity/shipping-delivery/presets` | 分页列出本店未退役发货预设 | safe | `identity.shipping.read` |
| `GET /merch/identity/shipping-delivery/presets/{presetId}` | 读取一条预设（含分区） | safe | `identity.shipping.read` |
| `POST /merch/identity/shipping-delivery/presets` | 创建发货预设 | `commandKey` | `identity.shipping.manage` |
| `PUT /merch/identity/shipping-delivery/presets/{presetId}` | 按版本编辑 | `commandKey` | `identity.shipping.manage` |
| `POST /merch/identity/shipping-delivery/presets/{presetId}/enable` | 启用 | `commandKey` | `identity.shipping.manage` |
| `POST /merch/identity/shipping-delivery/presets/{presetId}/disable` | 停用 | `commandKey` | `identity.shipping.manage` |
| `POST /merch/identity/shipping-delivery/presets/{presetId}/retire` | 退役发货预设 | `commandKey` | `identity.shipping.manage` |

列表/详情响应附带该店 `shipping` 平台叠加层：`platformStatus`、`platformReasonPublic`、`editable`。叠加层非 `active` 时写接口失败关闭。

旧路径 `/commercial/settings/shipping*` 与 `/commercial/settings/shipping-presets*` 不再提供。本页不发货、不写订单履约轴。
