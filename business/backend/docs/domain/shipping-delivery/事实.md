# 发货/配送业务事实

Identity 的 `fulfillment` capability 拥有店铺配送规则和发货预设。这不是订单发货单，也不计算 Trade 报价；Trade 后续只读取版本化公开契约。客服、物流轨迹和售后不在本页。

## 旧系统到当前模型的逐项对照

### 配送规则（旧 `ShippingRule`）

| 旧表/接口字段 | 旧语义证据 | 当前字段 | 迁移规则 |
|---|---|---|---|
| `id` | 规则主键 | `rule_id` | 新表自增；不沿用旧主键 |
| `appid` + `commercial_id` | 旧运行时隔离键 | 非运行时 | 必须解析到 `merchant_id + shop_id` |
| `name` | 规则名称 | `name` | trim，1–120 字符 |
| `regions` | 覆盖区域文本 | `regions` | trim，1–2000 字符 |
| `fee_fen` | 运费分 | `fee_fen` | `>= 0` |
| `free_over_fen` | 满额包邮分；0 表示不启用 | `free_over_fen` | `>= 0` |
| `min_days` / `max_days` | 时效天数 | 同名字段 | `0 ≤ min_days ≤ max_days ≤ 365` |
| `sort_order` | 展示顺序 | `sort_order` | 整数 |
| `merchant_status` `active`/`disabled` | 商户启停 | `status` `ACTIVE`/`DISABLED` | 大小写对齐 |
| `platform_status` | 旧行复制治理状态 | `identity_merchant_capability` `module=shipping` | 禁止复制到规则行 |
| `POST .../shipping/delete` | 物理删除 | `RETIRED` | 不物理删除；列表默认不展示退役行 |

### 发货预设（旧 `ShippingPreset`）

| 旧表/接口字段 | 旧语义证据 | 当前字段 | 迁移规则 |
|---|---|---|---|
| `id` | 预设主键 | `preset_id` | 新表自增 |
| `name` / `is_default` | 名称与默认标记 | 同名字段 | 同店未退役预设最多一个默认 |
| `product_scope` / `product_ids` | 商品范围 | `ALL` / `SELECTED` + `product_ids` | `product_id` 是 Catalog 引用，不是外键；`ALL` 时必须空列表 |
| `origin_*` | 发货地 | 同名字段 | 国家码大写 ISO 3166-1 alpha-2 |
| `status` | 启停 | `ACTIVE`/`DISABLED` | 退役为 `RETIRED` |
| `zones[]` | 分区、地区与费率 | `zones_json` | 作为预设聚合保存；区/费率 id 仅在该预设内稳定 |
| `POST .../status` | 启停 | `enable` / `disable` | 封闭方法词 |
| `DELETE .../{id}` | 物理删除 | `retire` | 不物理删除 |

## 唯一事实源

- 配送规则：`identity_shipping_rule`。
- 发货预设：`identity_shipping_preset`（分区费率存在 `zones_json`）。
- 幂等结果：`identity_shipping_rule_command`、`identity_shipping_preset_command`。
- 平台叠加层：`identity_merchant_capability`（`module=shipping`），只读，不入库。
- 关闭店铺后读写均视为范围不存在。

菜单可见性仍受订阅权益约束。默认套餐不含 `identity.shipping.read` / `identity.shipping.manage`。
