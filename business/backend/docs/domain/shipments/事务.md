# 商户物流发货事务与失败窗口

## 商户列表与详情

1. merch 逻辑从 Module Session 读取 `merchant_id + shop_id`；缺失即拒绝。
2. 规范化筛选与分页。
3. 开启 Identity MySQL 只读事务（`REPEATABLE READ`）。
4. 校验未关闭店铺行；关闭或缺失则失败。
5. 按店铺范围统计并分页读取，或按 `shipment_id` 读取单行（含轨迹 JSON）。
6. 提交只读事务。不写命令账本、不写 Outbox。

## 发货 / 追加轨迹 / 确认收货

1. 规范化 `commandKey`、订单引用、承运商、运单号或轨迹节点，以及 `expectedVersion`。
2. 开启写事务。插入命令账本行；主键冲突则按摘要决定重放或幂等冲突。
3. 锁定未关闭店铺；写操作再锁定发货单行（发货则插入新行并校验同店订单唯一）。
4. 版本、状态或唯一键不满足则失败并回滚。
5. 条件更新或插入后回写命令回执并提交。
6. 失败整笔回滚。不更新 Trade 订单，不发承运商请求。

## 失败与恢复

- 店铺范围失败不返回其他店铺发货单。
- 列表失败可安全重试。
- 写失败后客户端用新 `commandKey` 或原 key 重试；原 key 且摘要相同则重放。
