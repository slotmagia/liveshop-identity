# 商户物流发货不变量

1. 每条发货单必须绑定同一 `identity_shop` 行证明的 `merchant_id + shop_id`；两个维度不得由浏览器拼接或互相替代。`app_id`/`commercial_id` 不是运行时标识。
2. 商户范围只来自 merch Module Session。请求不得携带 `merchantId`/`shopId`，也不得改查另一店铺。
3. `order_id > 0`。Identity 不校验 Trade 订单是否仍存在。同一店铺同一 `order_id` 只能有一条发货单。
4. `carrier` 与 `tracking_no` 为 1–64。`traces[].node` 为 1–200；单票最多 100 条轨迹。
5. `status` 只能是 `SHIPPED|DELIVERED`。发货创建为 `SHIPPED`；只有 `SHIPPED` 可追加轨迹或 `close` 为 `DELIVERED`。`DELIVERED` 是终态。
6. 写命令必须带 8–128 的 `commandKey`。发货 `expectedVersion=0`；轨迹与确认收货必须带当前 `expectedVersion`。相同 key 相同摘要重放同一结果；相同 key 不同摘要冲突。
7. 关闭或缺失店铺不能列出、读取或改写发货单。
8. 本切片不提供删除 HTTP，不保存运费、电子面单或承运商账号，不写 Trade 订单状态。
