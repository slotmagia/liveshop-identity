# Identity 业务事实

Identity 是 LiveShop 全端共享的认证身份与组织目录模块。Admin、Merch、Shop、Live 是使用能力的 surface，不是四套身份事实源。

## 拥有的事实

| 事实 | 唯一存储 | 唯一写入方 | 派生消费者 | 失效/过期规则 |
|---|---|---|---|---|
| 全局用户主体、realm、principal type 与旧用户映射 | `identity_subject` | Identity 主体用例 | Gateway、Host、Platform Audit、一次性业务数据迁移与各业务模块 | `subject` 全局稳定；`legacy_uid` 只用于迁移解析且 `(realm, legacy_uid)` 唯一；关闭后不可重新登录 |
| 登录凭据、锁定与验证状态 | `identity_credential` | Identity 凭据用例 | Identity 认证边界 | 管理员重置撤销该主体全部活动会话；商户自助改密撤销其它会话并保留当前 Module Session |
| 店铺游客主体与可恢复会话 | `identity_subject`（`GUEST`）、`identity_session`、`identity_refresh_token` | Identity 游客会话用例 | Shop、Live Host 与游客可用模块 | 主体随机且全局稳定；会话绑定一个活动店铺；refresh 轮换、登出或过期后失效 |
| Access Identity 对应的登录会话和 refresh token | `identity_session`、`identity_refresh_token` | Identity 会话用例；商户设备登录只能自助撤销当前 subject | Gateway 与 Host | refresh 单次轮换；登出、停用、自助撤销或重用后撤销 |
| 商户主体 | `identity_merchant`、`identity_merchant_command` | Identity 商户开户与商户资料用例 | Platform、Catalog、Trade、Merch 商户信息页 | 关闭为终态；状态写入检查版本；自服务资料不改公司名/账号/状态 |
| 商户当前套餐指派 | `subscription_merchant_assignment`、`subscription_merchant_assignment_command` | Identity 商户管理页指派 | 有效授权计算 | 键是 `merchant_id`；指派后应用套餐权限模板和商品配额 |
| 店铺、`shop_id` 与 `merchant_id` 的权威对应，以及店铺结算币种 | `identity_shop`（`currency` 为大写 ISO 4217 三字母值） | Identity 店铺用例 | Gateway 边缘解析、Catalog、Trade 等业务模块 | 停用后不得建立新的商业上下文；币种缺失或非规范值时只读契约失败关闭 |
| 平台组织、商户组织及组织单元 | `identity_organization`、`identity_organization_unit` | Identity 组织用例 | Identity IAM、Admin、Merch | 只存在平台、商户两类人员组织 |
| 平台操作员、商户所有者、员工、主播成员 | `identity_workforce_member`、`identity_organization_membership` | Identity workforce 用例 | Identity Authorization、Admin、Merch | 只有 ACTIVE 成员可取得新业务授权 |
| 员工多店和主播固定店铺关系 | `identity_member_shop` | Identity workforce 用例 | Identity IAM、Live | `OPERATE` 可多店；`ANCHOR` 固定单店 |
| 待发布身份/组织事件 | `identity_outbox` | 与权威写入相同事务 | Platform、审计和业务消费者 | 成功投递后保留投递时间用于审计 |
| 已消费外部事件 | `identity_inbox` | Identity 消费者 | 本模块去重与恢复 | 按运维保留策略清理 |
| 授权域、角色、角色策略、Subject grant、数据范围与授权 revision | `identity_authorization_*` | Identity IAM 用例 | Module Capability、Admin、Merch | 条件更新；每次策略/grant 变化递增 domain revision |
| 活动权限和 Contribution 投影 | `identity_registry_*` | Identity Registry 同步器通过 mTLS 拉取 Platform 完整活动快照 | Identity IAM 与 Module Capability | 只接受更高 registry revision；同 revision 内容冲突、缺失或过期均失败关闭 |
| 商户 permission entitlement 当前状态 | `subscription_permission_entitlement_state`、`subscription_permission_entitlement_item` | Identity Subscription capability | Identity 有效授权计算 | 命令幂等；revision 单调递增；同 revision 不同 digest 拒绝 |
| 商户权益授权读模型 | `identity_entitlement_projection`、`identity_entitlement_projection_state` | Identity 内部 entitlement 同步器从同库 Subscription capability 原子刷新 | 有效授权计算 | 更高 revision 原子替换；同 revision 同 digest 只刷新新鲜度；旧 revision 或同 revision 不同 digest 拒绝 |
| 店铺外部客服账号 | `identity_customer_service_account`、`identity_customer_service_command` | Identity Customer Service capability | Admin、Merch、Live 与 Shop 展示消费者 | 绑定权威 `merchant_id + shop_id`；更新校验版本；删除行后幂等结果仍可重放 |
| 店铺客户隐私文档 | `identity_shop_privacy`、`identity_shop_privacy_command` | Identity shop capability | Merch 设置页；Live analytics 消费同意快照 | 绑定权威 `merchant_id + shop_id`；缺行返回默认值；更新校验版本；平台叠加层不入库 |
| 店铺政策版本 | `identity_shop_policy`、`identity_shop_policy_command` | Identity shop capability | Merch 政策页；Shop/Live 只读消费者后续接入 | 绑定权威 `merchant_id + shop_id`；每次保存新版本；发布归档同类型旧发布版；平台叠加层不入库 |
| 店铺私有应用凭据 | `identity_shop_app`、`identity_shop_app_command` | Identity shop capability | Merch 应用页 | 绑定权威 `merchant_id + shop_id`；密钥只存散列；明文仅创建/轮换返回；平台叠加层不入库 |
| 店铺游客风险事件 | `identity_risk_event` | Identity risk capability；本切片仅 merch 只读 | Merch 风控记录页；后续 Live 行为信号写入 | 绑定权威 `merchant_id + shop_id`；只追加；`room_id` 是 Live 房间引用 |
| 店铺游客当前风险快照 | `identity_visitor_risk` | Identity risk capability | 列表 JOIN 当前分/等级/状态；后续版本化决策消费者 | 键是 `(merchant_id, shop_id, visitor_id)`；旧 revision 不得覆盖新决策 |

## 明确不拥有的相邻事实

| 事实 | 拥有者 | Identity 如何使用 | 本地语义 |
|---|---|---|---|
| 权限定义和活动 Contribution | Platform Registry | Identity 消费版本化活动目录形成只读投影 | 投影不可本地编辑；Registry revision 是来源版本 |
| 模块注册、Settings、平台审计 | Platform | 通过公开契约或事件交互 | 不复制控制面事实 |
| 顾客昵称、会员等级、偏好、地址、CRM | Identity Customer capability | 通过稳定 `subject`/旧 `uid` 关联 | 与认证主体共享模块边界，但保持独立 capability 模型 |
| 商品、订单、支付等业务状态 | 对应业务模块 | claims 或公开契约提供身份与商业上下文 | 不保存业务聚合副本 |

## 领域标识和隔离语义

以下标识不可合并或替代：

| 标识 | 语义 |
|---|---|
| `merchant_id` | 商户主体 ID，一个商户可拥有多个店铺 |
| `shop_id` | 店铺实体主键；店铺隔离只与 `merchant_id` 组成运行时范围 |
| `staff_id` | 旧商户员工 ID；迁移为 `legacy_staff_id`，新成员使用 `member_id` |
| `subject` | 全局稳定认证主体 ID，不携带或运行时推算租户范围 |
| `uid` | 旧 C 端用户标识；迁移时建立与 `subject` 的持久化映射 |

- `app_id` 与 `commercial_id` 不再是运行时标识，也不进入 claims。历史 migration `001-014` 残留列不是现行范围键。
- `shop_id` 不能映射为组织单元或 IAM department。
- `identity_merchant` 以 `merchant_id` 为主键；`identity_shop` 以 `shop_id` 为主键并归属一个 `merchant_id`。
- 旧员工店铺范围 `(staff_id, appid, commercial_id)` 只能在校验店铺归属后迁移成 `merchant_id + shop_id`；`identity_member_shop.shop_id` 是权威关系，Module Capability 中必须展开完整 ShopScope。
- 旧总后台 `platform_admin_user.role_key` 一对一迁移为稳定 role.code；marketplace finance、visitor risk、provider config、AB governance 的代码角色集合转换为 Registry 权限 grant，不在 Identity 继续硬编码角色名单。
- 商业上下文是 `(merchant_id, shop_id)` 的已验证组合，不是任何一张表的复合主体主键。
- 店铺结算币种是 `identity_shop.currency` 拥有的店铺配置事实，但不是商业身份的一部分；它由 `ResolveShopContext.currency` 单独发布，禁止加入 `ShopContext` 后参与身份相等、授权或隔离判断。
- 旧项目 `internal/aggregator/common/shop.Shop.Currency` 是结算币种来源，报价和下单在币种缺失时明确失败，并在报价币种变化时拒绝下单；目标实现一对一承载为 `identity_shop.currency`，不由 Catalog、Trade 或浏览器请求推断。
- 浏览器提交的店铺选择只是候选值；Identity 校验真实关系后才能进入签名 Access Identity 或 Module Capability。
- Admin、Merch、Shop、Live 是 surface。Shop 是业务范围，Live 主播是岗位身份；二者都不形成独立人员组织树。
- 四端边界与店铺隔离见 [`模块开发规范.md`](../模块开发规范.md) §L0.2。
