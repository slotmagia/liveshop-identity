# 店铺政策不变量

1. 政策行必须绑定同一 `identity_shop` 证明的 `merchant_id + shop_id`；关闭店铺不能写入。
2. `(shop_id, policy_type, version_no)` 唯一；`version_no` 按店铺和类型单调递增。
3. 标题 1–255 个字符，正文 10–20000 个字符；类型只能是 `privacy|terms|refund|shipping`。
4. 不允许就地编辑或删除。新内容只能作为新版本插入。
5. 同一店铺同一类型最多一条 `PUBLISHED`。发布或保存并发布时，旧发布版必须在同一事务归档。
6. 平台叠加层不得写入 `identity_shop_policy`。非 `active` 叠加层阻止发布和保存并发布，但允许保存草稿。
7. 写命令必须带 8–128 位 `commandKey`。相同键相同摘要重放首次结果；相同键不同摘要拒绝。
8. 浏览器不得提交 `merchant_id`。会话绑定店铺时，请求 `shopId` 必须与 claims 一致。
