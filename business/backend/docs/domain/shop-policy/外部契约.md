# 店铺政策对外契约

Merch HTTP surface 使用会话中的 `merchant_id`，浏览器只提交 `shopId`：

- `GET /merch/identity/policies/shops`：列出当前商户未关闭店铺。会话绑定店铺时只返回该店。权限 `identity.policy.read`。
- `GET /merch/identity/policies`：按店铺列出政策版本，可筛类型和状态，分页。响应附带该店 `policies` 平台叠加层。权限 `identity.policy.read`。
- `POST /merch/identity/policies`：新建版本。`publish=false` 插入草稿；`publish=true` 直接发布。权限 `identity.policy.manage`。
- `POST /merch/identity/policies/{policyId}/publish`：按 `expectedVersion` 发布草稿。权限 `identity.policy.manage`。

写契约要求 `commandKey`。响应返回规范化政策、当前版本和 `replayed`。Manifest Contribution `identity.merch.policies` 路由仍是 `/settings/policies`。

平台叠加层读写仍走总后台商户能力治理；本页只读展示，不提供干预入口。
