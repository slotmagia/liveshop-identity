# 商户后台「政策」迁移对照

## 旧页面与接口证据

- 菜单：`menu.settings_policies`，路由 `/settings/policies`。
- 旧前端：`woklive-merchant/src/views/business/settings/module.tsx`（`PoliciesPage`）。
- 旧接口：
  - `GET /commercial/settings/policies?policy_type=`
  - `POST /commercial/settings/policies/save`（`policy_type`、`title`、`content`、`publish`）
  - `POST /commercial/settings/policies/publish`（`id`）
- 旧类型：`privacy | terms | refund | shipping`。
- 旧表：`shop_policy_version`，范围是 `appid + commercial_id`，并把 `platform_status` 存在政策行上。发布要求平台状态为 `active`。每次保存生成新版本；正文最短 10 个字符。

## 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `appid + commercial_id` | `merchant_id + shop_id` | 运行时不再使用应用/商业隔离 ID。 |
| `policy_type` | `policy_type` | 枚举保持不变。 |
| `title` / `content` | `title` / `content` | 标题 1–255，正文 10–20000 个字符。 |
| 每次保存新版本 | `identity_shop_policy` 新行 | 禁止就地编辑和删除。 |
| `publish=true` | 插入 `PUBLISHED` 并归档旧发布版 | 同一店铺同一类型只保留一条有效发布。 |
| 行上 `platform_status` | `identity_merchant_capability.module='policies'` | 不把平台状态复制到政策行；缺行视为 active。 |
| 无命令键 | `commandKey` | 所有写命令可安全重试。 |
| 无乐观锁 | `version` + 发布 `expectedVersion` | 并发发布失败关闭。 |

## 页面迁移结果

- 菜单目录、名称和 `/settings/policies` 保持不变。
- 查询卡选择店铺、类型和状态；数据卡列出版本、商户状态、平台叠加层和摘要。
- 刷新、新建版本在数据卡工具栏；详情和发布在行内。表单和确认使用 `hostFormModal()`。
- 无 `identity.policy.manage` 时隐藏写按钮。平台受限时仍可保存草稿，不能发布。
