# 店铺政策事实源

- Identity shop capability 拥有店铺政策正文与商户发布生命周期。政策不是独立发布模块，也不复制到 Platform。
- 运行时范围只有 `merchant_id + shop_id`。`app_id` / `commercial_id` 不是标识，也不进入政策行。
- 政策类型固定为 `privacy`、`terms`、`refund`、`shipping`。每次保存插入新版本，不覆盖旧行，不提供删除。
- 商户状态是 `DRAFT → PUBLISHED → ARCHIVED`。同一店铺同一类型同时最多一条 `PUBLISHED`；发布时把旧发布版归档。
- 平台叠加层仍在 `identity_merchant_capability`（`module='policies'`）。政策行不复制 `platform_status`。缺叠加层行视为 `active`。
- 旧商户后台 `/settings/policies` 的 `GET/POST /commercial/settings/policies*` 由本 capability 承接；菜单路由保持 `/settings/policies`。
