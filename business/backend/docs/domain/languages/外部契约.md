# 店铺语言对外契约

- `GET /merch/identity/languages`：`identity.language.read`
- `PUT /merch/identity/languages`：`identity.language.manage`；`commandKey` + `expectedVersion`
- `POST /auth/guest`、`GET /auth/me` 在顾客域返回 `defaultLocale`、`publishedLocales[]`；`suggestedLocale` 第一期可空

内部编排：`GET /internal/platform/i18n/locales|texts|entities`，浏览器不得出现在本页 `allowedRoutes`。
