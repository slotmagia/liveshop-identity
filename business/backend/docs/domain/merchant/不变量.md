# 商户管理不变量

- 开户、编辑、自服务资料、重置密码、关闭和套餐指派都必须带稳定 `commandKey`。相同键相同摘要重放，不同摘要拒绝。
- 编辑、自服务资料和关闭必须携带当前 `expectedVersion`；冲突不得覆盖。
- 关闭后不得再编辑、更新资料、重置密码或重新开户到同一 `merchant_id`。
- 商户后台资料命令不得改写公司名、状态或登录账号；`merchant_id` 只来自 Module Session。
- 自服务资料仅 `MERCHANT_OWNER` 可读写；误授 `identity.profile.manage` 也不能让员工改商户主体。
- 默认店铺写入不得带 `app_id`/`commercial_id`。
- 登录账号全局唯一，且不得写入 `identity_merchant`。账号只接受用户名或邮箱，并按小写比较。
- 套餐指派键是 `merchant_id`。`durationDays=0` 表示永久，`expires_at` 为空。
- 支付、短信、流媒体行不进入 Identity 库；编排前必须用本模块店铺目录校验 `merchant_id + shop_id`。
