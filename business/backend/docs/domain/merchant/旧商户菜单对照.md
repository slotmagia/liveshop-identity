# 商户后台「商户信息」迁移对照

## 旧页面与接口证据

- 菜单：`menu.merchant_profile`，路由 `/merchant/profile`。
- 旧前端：`woklive-merchant/src/views/business/profile`。
- 旧接口：
  - `GET /commercial/profile`：返回商户基础字段与自服务字段。
  - `POST /commercial/profile/update`：只更新自服务字段，不含账号、公司名、状态。
- 旧自服务字段：`external_id`、`contact_first_name`、`contact_last_name`、`contact_phone`、`marketing_email_opt_in`、`marketing_sms_opt_in`。
- 旧访问：仅 Owner 可进入。

## 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `appid + commercial_id` | `merchant_id` | 只从 merch Module Session 读取；浏览器不得提交商户 ID。 |
| 公司名 / 账号 / 状态 | `name` / `account` / `status` | 只读展示。公司名与状态仍由总后台商户管理写入。 |
| `external_id` | `external_id` | trim；最长 64。 |
| `contact_first_name` + `contact_last_name` | `contact_name` | 当前商户行已是单一联系人；不再拆名。 |
| `contact_phone` | `contact_phone` | trim；最长 32。 |
| `marketing_email_opt_in` / `marketing_sms_opt_in` | 同名布尔列 | 商户接收平台营销触达的偏好，不是店铺顾客营销同意。 |
| `POST` 覆盖写 | `PUT` + `commandKey` + `expectedVersion` | 同键同摘要重放，冲突失败关闭。 |
| 仅 Owner | `MERCHANT_OWNER` | 权限不足或主体不是所有者都失败关闭。 |

## 页面迁移结果

- 菜单目录、名称和 `/merchant/profile` 保持不变。
- Contribution 为 `identity.merch.profile`，权限 `identity.profile.manage`。
- Host 菜单说明卡 + 数据卡「联系与对接」；刷新/保存在工具栏。只读展示公司名、登录账号、状态。可编辑字段对齐旧页：公司 ID、联系人、电话、营销状态勾选。旧「名字 + 姓氏」合并为单一 `contactName`。瞬时反馈走 `notify()`，不把 `statusLine` 写入数据卡。
