# 商户管理事务

- 开户：分配 ID、写商户/组织/授权域/默认店铺/OWNER/凭据/店铺绑定，并完成命令账本，同一事务提交。
- 编辑：锁商户行，校验版本与非 `CLOSED`，同步组织名和 OWNER 展示名。
- 自服务资料：锁商户行，校验版本与非 `CLOSED`，只更新外部编号、联系人、电话和营销偏好，不同步组织名或凭据。
- 重置密码：版本化改密并撤销该 OWNER 活动会话。
- 关闭：同一事务关闭商户、店铺、组织、单元，撤销成员与店铺绑定，关闭凭据并撤销会话。
- 套餐指派：写入 assignment 后，用派生命令键应用权限模板和 `catalog.products` 配额。指派成功但权益应用失败不得假装完成。
