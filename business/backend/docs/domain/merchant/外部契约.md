# 商户管理对外契约

Admin HTTP surface 使用 `identity.merchant.manage` 权限。Contribution `identity.admin.merchants` 只开放 `/admin/identity/merchants`。

| 路径 | 方法 | 说明 |
|---|---|---|
| `/admin/identity/merchants` | GET | 分页列表；关键字匹配名称、登录账号、`external_id`；默认排除 `CLOSED` |
| `/admin/identity/merchants` | POST | 单事务开户；`commandKey` 幂等；成功回显 `merchantId`、`shopId`、`shopCode`、`account` |
| `/admin/identity/merchants/{merchantId}` | PUT | 编辑名称和 `ACTIVE\|DISABLED`；账号只读；`commandKey` + `expectedVersion` |
| `/admin/identity/merchants/{merchantId}/credentials/reset` | POST | 重置 OWNER 凭据并撤销其活动会话 |
| `/admin/identity/merchants/{merchantId}/close` | POST | 关闭终态 |
| `/admin/identity/merchants/{merchantId}/shops` | GET | 本模块店铺目录，供支付/短信先选店 |
| `/admin/identity/merchants/subscription-plans` | GET | 活动套餐目录，供本页指派 |
| `/admin/identity/merchants/{merchantId}/subscription` | GET/PUT | 当前套餐指派；PUT 后应用权限模板和商品配额 |
| `/admin/identity/merchants/{merchantId}/payment-channels` | GET/PUT | Identity 编排 Trade `merchant-channels`；查询必须带 `shopId` |
| `/admin/identity/merchants/{merchantId}/sms-regions` | GET/PUT | Identity 编排 Platform SMS grants；查询必须带 `shopId`；GET 附带区域管理中已启用的 `regions` 目录 |
| `/admin/identity/merchants/{merchantId}/live-providers` | GET/PUT | Identity 编排 Platform 流媒体授权；商户级，不按店拆 |

Merch HTTP surface 使用 `identity.profile.manage`。Contribution `identity.merch.profile` 只开放 `/merch/identity/profile`。

| 路径 | 方法 | 说明 |
|---|---|---|
| `/merch/identity/profile` | GET | 当前会话商户资料；账号、公司名、状态只读 |
| `/merch/identity/profile` | PUT | Owner 更新自服务字段；`commandKey` + `expectedVersion` |

两项操作均要求 `identity.profile.manage`，并再次校验 `MERCHANT_OWNER`。不接受请求体或查询中的 `merchantId`。

现有只读选择器 `GET /admin/identity/shops/merchants` 不替换。iframe 不得直打 Trade/Platform 前缀；编排使用 workload 内部口和 `X-Liveshop-Internal-Grant`。
