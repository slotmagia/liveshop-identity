# 店铺管理对外契约

Admin HTTP surface 提供当前菜单专用只读契约：

- `GET /admin/identity/shops/merchants`：返回全部非关闭商户，按 `merchant_id` 倒序。
- `GET /admin/identity/shops?merchantId={merchant_id}`：`merchantId` 为空时返回全部非关闭店铺；有值时只返回该商户店铺。均按 `shop_id` 倒序。

两项接口均要求 `identity.shop.read` Module Capability，且 contribution 的 `allowedRoutes` 只开放 `/admin/identity/shops` GET 前缀。响应保持 `merchantId / shopId` 独立，并返回店铺名称、短码、子域名标识、默认语言、结算币种、状态和版本。claims 与响应均不再携带 `appId`/`commercialId`。

Merchant HTTP surface 提供商户本尊多店契约：

- `GET /merch/identity/shops`：当前会话商户的非关闭店铺分页列表；`identity.shop.read`。
- `GET /merch/identity/shops/current`：当前会话店铺资料；`identity.shop.read`。缺少会话店铺或店铺已关闭时拒绝。
- `GET /merch/identity/shops/categories`：建店可选的 `ACTIVE` 经营品类；`identity.shop.read`。
- `POST /merch/identity/shops`：新建店铺；`identity.shop.manage`，仅 `MERCHANT_OWNER`。
- `PUT /merch/identity/shops/{shopId}`：编辑名称和子域名；`identity.shop.manage`，仅 `MERCHANT_OWNER`。
- `POST /merch/identity/shops/{shopId}/enable`
- `POST /merch/identity/shops/{shopId}/disable`
- `POST /merch/identity/shops/{shopId}/close`

写命令均要求 `commandKey`；启停和关闭还要求 `expectedVersion`。响应返回规范化店铺和 `replayed`。浏览器不得提交 `merchantId`、短码、币种（编辑）或品类（编辑）。店铺语言见 `domain/languages/外部契约.md`。

模块后端编排只读目录时走内部口，不经过浏览器 Module Capability：

- `GET /internal/v1/directory/merchants`：与 Admin 商户目录相同，返回全部非关闭商户。
- `GET /internal/v1/directory/shops?merchantId=`：`merchantId` 为空时返回全部非关闭店铺；有值时只返回该商户店铺。

两项内部口要求 `X-Liveshop-Internal-Grant`，供 Live 等模块填充查询下拉，不得复制 Identity 商户/店铺事实。

完整公共访问 URL 必须等 Platform 提供版本化公共入口/域名读取契约后由组合层生成；Identity 不保存第二份全局域名设置。
