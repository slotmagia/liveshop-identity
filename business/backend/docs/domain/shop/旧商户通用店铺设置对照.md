# 商户后台「通用店铺设置」迁移对照

## 旧页面设计

- 菜单保持“商户中心 → 通用店铺设置 → `/settings/general`”，不并入店铺管理列表。
- 旧页读取当前活动店铺，只允许修改名称和子域名；币种、品类、状态只读。
- 旧前端用 `commercial_id` 在店铺列表中找活动店。目标页改为会话权威 `merchant_id + shop_id`，浏览器不得自报店铺。
- 旧页还列出建店、删除、像素和域名后缀接口，但页面实际只调用列表和更新。建店/关闭仍归 `/merchant/shops`；像素归 Catalog `ab_mapping`；域名后缀归 Platform。

## 字段与行为对照

| 旧字段 / 行为 | 旧承载 | 目标字段 / 行为 | 规则 |
|---|---|---|---|
| 当前店铺 | 列表中匹配 `commercial_id` | `GET /merch/identity/shops/current` | 只读会话 `shop_id`；关闭店不可见。 |
| 店铺名称 | 可编辑 `name` | `name` | 去除首尾空白，最长 191。 |
| 子域名 | 可编辑 `subdomain` | `identity_shop.subdomain` | 全局唯一标识；完整公网 URL 仍等 Platform 契约。 |
| 结算币种 | 只读 | `currency` | 创建后不可改。 |
| 经营品类 | 只读 `category_code` | `categoryCode` | 创建后不可改；展示启用品类名称。 |
| 状态 | 只读 `status=1/0` | `ACTIVE/DISABLED` | 本页不启停；启停在店铺管理。 |
| 短码 / 语言 | 旧页未展示 | 只读 `code` / `defaultLocale` | 创建后不可改。 |
| 保存 | `POST /commercial/shop/update` | `PUT /merch/identity/shops/{shopId}` | 复用店铺聚合更新；`commandKey` + `expectedVersion`；仅 OWNER。 |
| 联系人跳转 | `/merchant/profile` | 文案说明 | iframe 不跨页编排；联系人仍在商户信息。 |
| 店铺目录跳转 | `/merchant/shops` | 文案说明 | 新建、启停、关闭仍在店铺管理。 |
| 广告像素 / 域名后缀 | 共享 API 文件 | 不迁入本页 | 不是店铺身份事实。 |

## 目标页面交互

- 无查询卡。数据卡展示当前会话店铺资料。
- 可编辑字段仅名称和子域名；其余只读。
- 刷新、保存位于工具栏。员工只读；保存要求 `MERCHANT_OWNER` 与 `identity.shop.manage`。
