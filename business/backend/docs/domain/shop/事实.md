# 店铺事实源

- Identity 是商户主体、店铺实体以及 `shop_id / merchant_id` 权威对应关系的唯一事实源。`app_id`/`commercial_id` 不是运行时标识。
- 总后台“店铺管理”是只读下钻页，不创建、修改、停用或关闭店铺。默认店铺只由商户开户事务写入。
- 商户后台“店铺管理”是多店写入页：商户所有者在本商户范围内新建、编辑名称/子域名、启停和关闭店铺。
- 商户后台“通用店铺设置”是当前会话店铺的资料页：只编辑名称和子域名。店铺范围来自会话 `shop_id`，不是浏览器选择。新建、启停、关闭仍在店铺管理。
- 当前页的商户目录来自 `identity_merchant`，排除 `CLOSED`，保留 `ACTIVE` 与 `DISABLED` 供平台核查。
- 当前页的店铺目录来自 `identity_shop`，默认不选商户并列出全部非关闭店铺；选择商户后按真实 `merchant_id` 过滤。排除 `CLOSED`，保留 `ACTIVE` 与 `DISABLED`。
- 商户后台列表始终按会话 `merchant_id` 隔离，排除 `CLOSED`，保留 `ACTIVE` 与 `DISABLED`。
- `identity_shop.subdomain` 是店铺保存的子域名标识，不等同于 Platform 拥有的公共商城入口、根域名或完整域名绑定。
- `identity_shop.category_code` 是可空的稳定经营品类引用，创建后不可修改；可选目录只来自 `identity_shop_category` 的 `ACTIVE` 行。
- `identity_shop.code` 由 Identity 分配且全局唯一；调用方不得自报短码。
- Platform 拥有公共商城入口与全局域名配置。当前架构尚无可供 Identity workload 读取该配置的公开契约，因此本页只展示和复制权威店铺短码及子域名标识，不在 Identity 内复制 Platform 配置或猜测完整 URL。
- 广告像素、广告渠道不属于店铺身份事实，不写入 `identity_shop`。
