# 总后台「店铺管理」迁移对照

## 旧页面设计

- 菜单保持“商城中台 → 店铺管理 → `/shops`”。
- 旧页面左侧加载全部商户并默认选择第一项，右侧按选中商户加载店铺表格。
- 店铺表格展示店铺 ID、名称、短码、`commercial_id`、启停状态，以及参数模式和子域名模式访问链接。
- 参数模式复制 `https://{shop_domain}?code={code}`；子域名模式复制 `https://{domain_binding.host}`。配置或绑定缺失时显示空值。
- 页面本身没有新增、编辑、启停或删除操作；旧源码中共享 API 文件的写函数不属于该页面实际调用链。

## 字段与行为对照

| 旧字段 / 行为 | 旧承载 | 目标字段 / 行为 | 规则 |
|---|---|---|---|
| 商户主键 | `commercial_merchant.id` | `identity_merchant.merchant_id` | 主键语义保持为商户；旧页面标签 `commercial_id {merchant.id}` 是显示错误，不迁移该错误。 |
| 商户名称 | `commercial_merchant.name`，空时回退账号 | `identity_merchant.name` | Identity 商户名称非空；账号属于 owner 凭据，不复制到商户事实。 |
| 商户状态 | `status=1/其他` | `ACTIVE/DISABLED` | `CLOSED` 对应旧软删除，目录排除。 |
| 店铺 ID | `commercial_shop.id` | `identity_shop.shop_id` | 一对一拼写规范化。 |
| 应用 ID | `appid` | `app_id` | 一对一拼写规范化。 |
| 商业隔离维度 | `commercial_id` | `commercial_id` | 保持原值与原语义，不映射为 `merchant_id`。 |
| 店铺归属 | `merchant_id` | `merchant_id` | 只按真实商户归属过滤。 |
| 店铺短码 | `code` | `code` | 保持稳定短码。 |
| 店铺子域名 | `subdomain` / `domain_binding.host` | `identity_shop.subdomain` | 当前返回权威子域名标识；完整绑定 URL 等 Platform 公开读取契约。 |
| 店铺状态 | `status=1/其他` | `ACTIVE/DISABLED` | `CLOSED` 对应旧软删除，目录排除。 |
| 排序 | `id DESC` | `merchant_id DESC`、`shop_id DESC` | 保持旧列表从新到旧的顺序。 |

## 目标页面交互

- 使用独立查询卡选择商户，保持“选择商户后查看其店铺”的交互，不复制旧项目局部卡片样式。
- 数据卡展示店铺身份四元组、名称、短码、子域名、语言、币种、状态和版本。
- 行内提供短码与子域名标识复制；不生成缺少 Platform 配置依据的完整公网 URL。
- 刷新位于数据卡工具栏，页面标题和说明只由 Host 从 Manifest 渲染。
