# 商户后台「店铺管理」迁移对照

## 旧页面设计

- 菜单保持“商户中心 → 店铺管理 → `/merchant/shops`”。
- 旧页面由商户本尊维护名下店铺：列表、新建、编辑名称/子域名/状态、软删除。
- 建店表单读取启用品类目录，并自动分配短码；旧接口还携带广告像素、广告渠道和站点域名后缀。
- `/settings/general` 是独立菜单，不合并进本页；对照见 [旧商户通用店铺设置对照.md](./旧商户通用店铺设置对照.md)。

## 字段与行为对照

| 旧字段 / 行为 | 旧承载 | 目标字段 / 行为 | 规则 |
|---|---|---|---|
| 店铺列表 | `GET /commercial/shop/list` | `GET /merch/identity/shops` | 当前商户全部非关闭店铺；`CLOSED` 对应旧软删除。 |
| 店铺 ID | `commercial_shop.id` | `identity_shop.shop_id` | 一对一拼写规范化。 |
| 店铺名称 | `name` | `name` | 去除首尾空白，最长 191。 |
| 短码 | `code` | `code` | 服务端分配，创建后不可改。默认店沿用开户短码；后续店铺使用 `shop-{shop_id}`。 |
| 子域名 | `subdomain` | `identity_shop.subdomain` | 全局唯一标识；完整公网 URL 仍等 Platform 公开读取契约。 |
| 结算币种 | `currency` | `currency` | 创建时写入 ISO-4217；编辑不改币种。 |
| 默认语言 | 开户默认 `zh-CN` | `default_locale` | 创建默认 `zh-CN`；本页编辑不改语言。 |
| 经营品类 | `category_code` | `identity_shop.category_code` | 仅允许当前 `ACTIVE` 品类；创建后不可改。空值表示未选。 |
| 启停 | `status=1/0` | `ACTIVE/DISABLED` | 独立 enable/disable 命令，校验期望版本。 |
| 删除 | 软删除 | `CLOSED` 终态 | 不可恢复；至少保留一家非关闭店铺。 |
| 售卖品类下拉 | `GET /commercial/shop/categories` | `GET /merch/identity/shops/categories` | 只返回 `ACTIVE` 品类，不读 Catalog 商品分类。 |
| 站点后缀 | `GET /commercial/shop/domain-suffix` | 不迁入 Identity | Platform 拥有公共入口/根域名；本页只复制子域名标识。 |
| 广告像素 | `POST /commercial/shop/pixels` | 不迁入本页 | Catalog `ab_mapping` 拥有广告账户/像素事实。 |
| 广告渠道 | `ad_channel` | 不迁入本页 | 归因/渠道事实归 Platform telemetry 或 Catalog 映射，不是店铺身份。 |
| 切换活动店铺 | 前端店铺上下文 | 不迁入本页 | 会话店铺范围由 Host `/auth/context/switch` 选择，不是店铺聚合写命令。 |

## 目标页面交互

- 独立查询卡按名称/短码关键字和状态筛选；分页在数据卡底部。
- 数据卡展示店铺 ID、名称、短码、子域名、品类、语言/币种、状态和版本。
- 刷新、新建位于工具栏；编辑、启停、关闭、复制短码/子域名位于行内。
- 新建/编辑/关闭使用 `hostFormModal()`。写操作仅 `MERCHANT_OWNER` 可执行。
