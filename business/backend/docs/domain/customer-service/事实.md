# 客服账号业务事实

客服账号是店铺对外展示或直播渠道使用的联系账号，不是 LiveShop 登录凭据。Identity 的 `customer_service` capability 是唯一写入方。

## 旧系统到当前模型的逐项对照

| 旧表/接口字段 | 旧语义证据 | 当前字段 | 迁移规则 |
|---|---|---|---|
| `customer_service_account.id` | 客服账号主键 | `account_id` | 原值迁移；新数据自增 |
| `appid` | 应用维度 | 非运行时 | 只用于一次性导入解析，不写入现行客服事实 |
| `commercial_id` | 店铺旧业务隔离维度 | 非运行时 | 旧源分区键；必须解析到 `merchant_id + shop_id`，不得改名为 `merchant_id` |
| 无 | 旧表通过 `(appid, commercial_id)` 间接定位店铺 | `shop_id`、`merchant_id` | 迁移时必须由 `identity_shop` 唯一解析为现行店铺；无法解析即阻塞 |
| `platform` | 外部渠道稳定代码，`^[a-z0-9_-]{1,32}$` | `platform` | trim 后转小写 |
| `account` | 账号、手机号或外部平台 ID | `account` | trim，1–128 字符 |
| `nickname` | 对外展示昵称 | `nickname` | trim，最多 64 字符 |
| `status=1/0` | 启用/停用 | `ACTIVE` / `DISABLED` | 一对一状态映射 |
| `config` | 最大 4096 字符的可选 JSON 文本 | `config` | 保留原始 JSON 文本；空字符串合法 |
| `remark` | 管理备注 | `remark` | trim，最多 500 字符 |
| `created_at/updated_at` | 创建/更新时间 | 同名字段 | 原值保留 |

总后台列表默认不选商户和店铺，展示全部客服账号；也可按商户、再按店铺收窄。商户后台 `merchant_id` 只来自会话，列表默认展示本商户全部店铺账号，也可按 `shop_id` 收窄；浏览器不得提交或改写 `merchant_id`。列表按平台精确匹配、账号模糊匹配、状态精确匹配，按 `id DESC` 分页。新增、编辑和删除仍必须限定在明确 `merchant_id + shop_id` 范围内。

## 唯一事实源

- 客服账号事实：`identity_customer_service_account`。
- 店铺范围：`identity_shop`；客户端只提交 `merchant_id + shop_id`，服务端在事务内校验同一行并只保存这两个运行时标识。
- 幂等结果：`identity_customer_service_command`；同一 `command_key` 只能绑定一个请求摘要。
