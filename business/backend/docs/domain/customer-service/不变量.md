# 客服账号业务不变量

1. 每条客服账号必须绑定同一 `identity_shop` 行证明的 `merchant_id + shop_id`，两个维度不得由浏览器拼接或互相替代。`app_id`/`commercial_id` 不是运行时标识。
2. 同一店铺内 `(platform, account)` 唯一；其它店铺可以使用相同外部账号。
3. `platform` 始终为小写稳定代码；`account` 非空；`config` 为空或合法 JSON。
4. 列表可以不带 `merchant_id`/`shop_id`（表示全部），带了就必须按该范围过滤。商户后台会由会话写入 `merchant_id`，浏览器不得改写。更新和删除必须同时校验 `merchant_id + shop_id`；跨店铺目标表现为不存在，不能泄露其它店铺数据。
5. 更新和删除必须携带当前 `expected_version`；并发命令最多一个成功。
6. 同一 `command_key` 重放返回第一次已经提交的结果；用不同请求复用该 key 必须冲突，不能产生第二次写入。
7. 删除沿用旧系统可观察语义：账号从事实表永久删除并从列表消失；幂等命令账本保留已删除结果，重复删除命令不产生第二次副作用。
