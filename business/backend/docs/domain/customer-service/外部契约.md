# 客服账号外部契约

总后台页面继续使用菜单路由 `/customer-accounts`。商户后台「直播客服」继续使用 `/live/customer-service`，「商城管理 / 客服管理」继续使用 `/customer-accounts`；两页共用下列 merch 契约，不另建第二套接口。经 Gateway 调用本 capability 的 surface 契约。权限码均为 `identity.customer-account.manage`。写操作还经过当前授权复核。claims 与服务端范围都不携带 `appId`/`commercialId`。

### Admin

| 方法与路径 | 用途 | 幂等 |
|---|---|---|
| `GET /admin/identity/customer-accounts/merchants` | 可选商户目录 | safe |
| `GET /admin/identity/customer-accounts/shops?merchantId=` | `merchantId` 为空时返回全部非关闭店铺；有值时只返回该商户店铺 | safe |
| `GET /admin/identity/customer-accounts?...` | 分页查询；`merchantId`/`shopId` 可空表示全部 | safe |
| `POST /admin/identity/customer-accounts` | 创建客服账号 | `commandKey` |
| `PUT /admin/identity/customer-accounts/{accountId}` | 按版本编辑 | `commandKey` |
| `DELETE /admin/identity/customer-accounts/{accountId}` | 按版本删除 | `commandKey` |

Admin 写操作请求必须携带明确 `merchantId + shopId`。

### Merch

| 方法与路径 | 用途 | 幂等 |
|---|---|---|
| `GET /merch/identity/customer-accounts/shops` | 当前会话商户的店铺目录 | safe |
| `GET /merch/identity/customer-accounts?...` | 分页查询当前商户账号；`shopId` 可空表示本商户全部店铺 | safe |
| `POST /merch/identity/customer-accounts` | 在当前商户的指定店铺创建客服账号 | `commandKey` |
| `PUT /merch/identity/customer-accounts/{accountId}` | 按版本编辑 | `commandKey` |
| `DELETE /merch/identity/customer-accounts/{accountId}` | 按版本删除 | `commandKey` |

Merch `merchantId` 只来自 Module Session；写操作请求携带 `shopId`，服务端校验该店铺属于当前商户。会话已绑定店铺时不得改店。菜单可见性仍受订阅权益约束；默认套餐不含 `identity.customer-account.manage`。
