# 客服账号外部契约

总后台页面继续使用菜单路由 `/customer-accounts`，经 Gateway 调用以下唯一主契约：

| 方法与路径 | 用途 | 幂等 |
|---|---|---|
| `GET /admin/identity/customer-accounts/merchants` | 可选商户目录 | safe |
| `GET /admin/identity/customer-accounts/shops?merchantId=` | `merchantId` 为空时返回全部非关闭店铺；有值时只返回该商户店铺 | safe |
| `GET /admin/identity/customer-accounts?...` | 分页查询；`merchantId`/`shopId` 可空表示全部 | safe |
| `POST /admin/identity/customer-accounts` | 创建客服账号 | `commandKey` |
| `PUT /admin/identity/customer-accounts/{accountID}` | 按版本编辑 | `commandKey` |
| `DELETE /admin/identity/customer-accounts/{accountID}` | 按版本删除 | `commandKey` |

全部操作要求 `identity.customer-account.manage`。写操作还经过当前授权复核；请求必须携带明确 `merchantId + shopId`。claims 与服务端范围都不携带 `appId`/`commercialId`。
