# 客服账号事务边界

| 用例 | 同一事务内必须完成 | 失败恢复 |
|---|---|---|
| 创建 | 写入/锁定命令键、锁定并验证店铺四元组、检查唯一键、插入账号、保存完整响应 | 任一步失败整笔回滚；相同 key 重放既有结果 |
| 更新 | 写入/锁定命令键、锁定目标账号与店铺、校验版本、条件更新、保存完整响应 | 唯一键或版本冲突不留下命令账本；提交结果可重放 |
| 删除 | 写入/锁定命令键、锁定目标账号与店铺、校验版本、条件删除、保存删除前账号快照和删除结果 | 提交未知时用相同 key 重试；不会重复删除 |

不存在事务外业务副作用和消息发布。事务隔离使用 `REPEATABLE READ`；店铺、账号与命令行都在同一 Identity MySQL 事务内。
