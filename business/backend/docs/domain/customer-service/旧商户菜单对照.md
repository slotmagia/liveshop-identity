# 商户后台「直播客服」迁移对照

## 旧页面与接口证据

- 菜单：`frontend.live.customer-service`，路由 `/live/customer-service`。
- 旧前端：`woklive-merchant/src/views/business/live/operations`，与其它未接 API 的直播运营页共用骨架。
- 旧状态：仅完成布局，不发请求；业务动作禁用。
- 同模块已有真实商户接口（挂在「商城管理 / 客服管理」）：`/commercial/customer-accounts*`，按当前店铺维护外部客服账号。
- 实时直播互动、房间内会话仍归 Live，不在本页。

## 字段与范围映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `appid + commercial_id` | `merchant_id + shop_id` | `merchant_id` 只从 merch Module Session 读取；`shop_id` 为会话店或本商户店铺选择，服务端再次校验。 |
| 平台 / 账号 / 昵称 / 状态 / 配置 / 备注 | 同名字段 | 沿用 `customer_service` capability 既有规范化与唯一键。 |
| 覆盖写 | `POST/PUT/DELETE` + `commandKey` + `expectedVersion` | 同键同摘要重放；跨店目标表现为不存在。 |
| 未接线运营布局 | 店铺范围客服账号目录 | Identity 只提供客服账号事实，不提供直播互动。 |

## 页面迁移结果

- 菜单目录、名称和 `/live/customer-service` 保持不变。
- Contribution 为 `identity.merch.live-customer-service`，权限 `identity.customer-account.manage`。
- 与总后台客服管理、商城「客服管理」共用同一事实表和 merch HTTP；商城页贡献为 `identity.merch.customer-accounts`。
- Host 菜单说明卡 + `searchCard` + `dataCard`；新增/编辑/删除走 `hostFormModal()`。
