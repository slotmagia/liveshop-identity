# 旧总后台客服管理菜单迁移对照

| 项目 | 旧实现 | 当前实现 |
|---|---|---|
| 菜单 | 商城中台 / 客服管理 | 保持商城中台 / 客服管理，路由 `/customer-accounts` |
| 页面源码 | `woklive-admin/src/views/customer-accounts/index.tsx` | `business/frontend-admin/src/pages/customer-accounts.ts` |
| API | `/console/customer-accounts[/{id}]` | `/admin/identity/customer-accounts[/{accountID}]` |
| 商户/店铺选择 | 先商户，再按 `commercial_id` 选店铺 | 先商户，再以权威 `shop_id` 选店铺并展示 App/Commercial 标识 |
| 查询 | 平台、账号、状态 | 原样保留，分页参数进入数据卡底部分页而非搜索表单 |
| 操作 | 刷新、新增、编辑、删除 | 原样保留；新增/编辑使用 Host 表单模态框 |
| 表格 | 平台、账号、昵称、状态、备注、操作 | 保留并补充店铺范围、版本，便于总后台审计并发结果 |
