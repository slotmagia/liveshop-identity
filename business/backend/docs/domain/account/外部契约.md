# 商户账号总览与设备登录对外契约

账号总览是 merch 只读组合读模型，不新增权威表。设备登录复用 `account` 域操作当前登录主体自己的会话。

## HTTP

### 账号总览

- `GET /merch/identity/account`
- Operation：`identity.merch.account.get`
- 鉴权：Module Capability
- 权限：`identity.organization.read`
- 幂等：safe

响应只包含当前登录主体、所属商户、可访问店铺、当前套餐权益、有效权限名，以及组织单元/员工主播/店铺计数。不得返回其他成员凭据、角色编辑入口或写命令。

未指派套餐时 `subscription.planId=0`，HTTP 仍为 200。员工看不到未授权店铺。Owner 且 `AvailableShops` 为空时返回该商户全部店铺。

Manifest Contribution `identity.merch.organization` 的页面路由仍是 `/merchant`。

### 设备登录

- `GET /merch/identity/account/sessions`
- Operation：`identity.merch.account.sessions.list`
- 权限：`identity.organization.read`
- 查询：`status`（`ACTIVE` / `REVOKED`，空=全部未过期）、`page`、`pageSize`
- 响应：`items`（含 `current`）、`page`、`pageSize`、`total`
- 幂等：safe

- `POST /merch/identity/account/sessions/{sessionId}/revoke`
- Operation：`identity.merch.account.sessions.revoke`
- 权限：`identity.organization.read`
- 请求：`idempotencyKey`、`operationId`
- 响应：`currentRevoked`
- 幂等：idempotent

路径和请求体都没有 `{subject}`。owner、员工和主播只要持有 `identity.organization.read` 即可操作自己的设备。强制他人下线仍是 `GET/POST /merch/identity/members/{subject}/sessions...`，权限 `identity.session.manage`。

旧路径 `GET /commercial/account/me`、`POST /commercial/account/change-password`、`GET /commercial/settings/sessions`、`POST /commercial/settings/sessions/revoke` 不再提供。改密属于账号安全页 `/merchant/account/security`。
