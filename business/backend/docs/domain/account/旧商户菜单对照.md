# 商户后台「账号总览 / 设备登录」迁移对照

## 账号总览

- 菜单：`frontend.merchant.account`，路由 `/merchant`。
- 旧前端：`woklive-merchant/src/views/merchant-center/account`。
- 旧交互：展示当前商户/员工身份、店铺和入口；可跳转账号安全与设备登录。
- 旧接口：
  - `GET /commercial/account/me`
  - `POST /commercial/account/change-password`
- 改密属于账号安全 `/merchant/account/security`，不在本页提交。

### 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `uid` / `staff_id` | `subject` | 全局主体 ID；不再把旧整型主键当运行时标识。 |
| `account` / `name` | `account` / `displayName` | 登录标识来自当前成员凭据；显示名来自主体。 |
| `is_owner` / `role_code` | `owner` / `principalType` | 所有者由 principal type 判定；员工角色细节仍在角色管理。 |
| `merchant_id` / `merchant_name` | `merchant.merchantId` / `merchant.name` | 只从已验证 Module Session 与组织目录读取。 |
| `appid` | 不迁移 | 运行时隔离只用 `merchant_id + shop_id`。 |
| 店铺列表 | `shops[]` + `currentShopId` | 所有者可看名下店铺；员工/主播只看 `AvailableShops`。 |
| 权益入口 | `subscription` | 同模块 subscription 指派；未指派返回空套餐，不 404。 |
| 有效权限 | `permissionNames` | 当前成员有效授权标签；无授权时为空数组。 |
| 组织摘要 | `organization.unitCount` / `memberCount` / `shopCount` | 只计 STAFF+ANCHOR；不返回他人凭据或成员名单。 |
| `POST .../change-password` | `/merchant/account/security` | 本页只读；不改密、不撤销会话。 |
| 新建组织单元 / 启停员工 | `/merchant/users` | 账号总览不再写组织或人员。 |

### 页面迁移结果

- 菜单目录仍为「商户中心」，菜单仍为「账号总览」，路由仍为 `/merchant`。
- Contribution 仍为已发布的 `identity.merch.organization`；本页只请求 `GET /merch/identity/account`。
- 权限仍为 `identity.organization.read`，避免另开 entitlement。
- iframe 没有 Host `navigate()`，账号安全/设备登录继续走 Host 侧栏，本页不放失效跳转按钮。
- 页面结构：Host 菜单说明卡 + 上排两列数据卡（当前身份含组织计数、套餐权益与有效权限）+ 全宽可访问店铺表；`page({ showSummary: false })`；刷新在身份卡工具栏。

## 设备登录

- 菜单：`menu.settings_sessions`，路由 `/merchant/account/devices`。
- 旧前端：`woklive-merchant/src/views/business/settings/module.tsx`（`DevicesPage`）。
- 旧说明：只显示当前商户账号或当前员工账号自己的会话，不能查看其他员工设备。
- 旧接口：
  - `GET /commercial/settings/sessions` → `items[]`
  - `POST /commercial/settings/sessions/revoke`（`session_id`）→ `ok`、`current_revoked`
- 旧过滤：`merchant_id + staff_id`，`expires_at > now`；当前会话用 JWT `session_id` 比较。
- 旧交互：列表展示设备名、当前设备标记、IP、最近活动、到期；行内「退出当前设备」或「强制下线」；撤销当前设备后清 token 并跳登录页。

### 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `merchant_id + staff_id` | Module Capability `subject` | 不再按旧员工整型主键过滤；owner/员工/主播都是当前主体。 |
| `session_id` | `id` | Identity `identity_session.session_id`。 |
| `device_name` / `ip_address` / `status` | `deviceName` / `ipAddress` / `status` | 状态大写 `ACTIVE` / `REVOKED`。 |
| `last_seen_at` | `lastRefreshedAt` | 当前会话表没有独立 last_seen 列，用 refresh 时间表达最近活动。 |
| `expires_at` / `created_at` | `expiresAt` / `createdAt` | RFC3339。 |
| `current` | `current` | 服务端用 Capability `sessionId` 比较，且仅 ACTIVE 可标当前。 |
| `appid` | 不迁移 | 运行时隔离只用 `merchant_id + shop_id`。 |
| 无命令键 | `idempotencyKey` + `operationId` | 写命令可安全重试。 |
| `current_revoked` 后前端清 token 跳转 | `currentRevoked` | iframe 禁止访问父 DOM；页面提示重新登录，Host 在后续 401/授权复核后回到登录。 |
| 查看他人设备 | `/merchant/users` 会话 | 本页路径不含 `{subject}`，权限不是 `identity.session.manage`。 |

### 页面迁移结果

- 菜单目录仍为「商户中心」，菜单仍为「设备登录」，路由仍为 `/merchant/account/devices`。
- 占位 `identity.placeholder.merch.merchant-account-devices` 替换为 `identity.merch.devices`。
- 权限与账号总览相同：`identity.organization.read`，避免员工看不见自己的设备。
- 查询卡按状态筛选；数据卡列出设备、IP、状态、最近活动、到期；刷新在工具栏，撤销在行内。
- 表单确认使用 `hostFormModal()`；分页在数据卡底部。
