# 商户账号不变量

| 编号 | 不变量 | 保持机制 |
|---|---|---|
| ACC-INV-1 | 账号总览只返回当前 Module Capability 的 subject、merchant 与可访问店铺 | 逻辑层用 claims 解析 PrincipalContext，不接受请求体主体 |
| ACC-INV-2 | 设备登录只能列出和撤销当前 subject 自己的会话 | 路径和请求体没有 `{subject}`；自助校验 `OWNER/STAFF/ANCHOR` 成员，不走员工管理的 STAFF/ANCHOR 谓词；仓储按 `session_id + subject` 锁定 |
| ACC-INV-3 | 猜测他人 `sessionId` 不得泄露该会话是否存在于别的主体 | 外键式查找失败统一 `ErrNotFound` |
| ACC-INV-4 | 已过期会话不出现在设备登录列表 | `expires_at > now`；过期行仍可被登出/refresh 状态机处理 |
| ACC-INV-5 | 撤销当前会话后，后续写请求立即失败关闭 | 写中间件复核 `identity_session` 仍为 ACTIVE；本页返回 `currentRevoked` |
| ACC-INV-6 | 重复撤销同一会话收敛为既有结果 | `idempotencyKey` + 请求摘要；已撤销行不再改写 `revoke_reason` |
