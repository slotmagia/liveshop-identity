# 商户账号设备会话事务

## 列表

只读。按当前 `subject` 读取 `identity_session`，过滤未过期行后分页。不写命令账本。

## 自助撤销

1. 规范化 `sessionId`、`idempotencyKey`、`operationId`；subject 只来自 Module Capability。
2. 开启 Identity MySQL 事务。
3. 插入 `revoke_sessions` 命令账本；撞键时核对请求摘要并重放。
4. 校验当前 subject 是该商户组织未撤销的 `OWNER` / `STAFF` / `ANCHOR` 成员。不使用员工管理的 STAFF/ANCHOR 谓词，否则所有者会 `fact not found`。
5. `SELECT ... FOR UPDATE` 锁定 `session_id + subject`；找不到则 `ErrNotFound`。
6. 将活动 session 更新为 `REVOKED`，`revoke_reason` 在为空时写入 `SELF_REVOKED`；活动 refresh token 同步 `REVOKED`。
7. 同事务写 `identity.session.changed` Outbox 后提交。

## 失败与恢复

- 命令账本插入后业务写入失败：事务回滚。
- 提交结果未知：调用方用相同 `idempotencyKey` 重试。
- 撤销当前设备后，本请求已通过写前授权复核；后续写请求因 session 不再 ACTIVE 而 403。Host 需重新登录，iframe 不得访问父页面 DOM 自行跳转。
