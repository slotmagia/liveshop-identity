# 商户账号只读组合与设备会话

账号总览是 merch 只读组合读模型，不新增权威表。设备登录复用同一 `account` 域，读取并撤销当前登录主体自己的 `identity_session`。

## 账号总览

主体、组织、店铺范围、套餐指派和有效授权仍由既有 Identity 事实拥有。本页不写会话。

## 设备登录

| 事实 | 唯一存储 | 本页写入方 | 说明 |
|---|---|---|---|
| Access Identity 登录会话 | `identity_session` | 当前主体自助撤销 | 列表只返回当前 Module Capability `subject` 且未过期的会话 |
| Refresh token | `identity_refresh_token` | 与会话撤销同一事务 | 指定 session 的活动 refresh 一并 `REVOKED` |
| 命令账本 | 既有 `revoke_sessions` 幂等账本 | `commandKey` = `idempotencyKey` | 与用户管理强制下线共用账本命令名，请求摘要含 `SELF_REVOKED` 与当前 subject |

浏览器不得提交 `subject`。用户管理页的 `identity.session.manage` 仍是 owner 管理他人会话的路径，本页不能替代。
