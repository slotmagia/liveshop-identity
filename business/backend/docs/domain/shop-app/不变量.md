# 店铺私有应用不变量

1. 应用行必须绑定同一 `identity_shop` 证明的 `merchant_id + shop_id`；关闭店铺不能读写。
2. `client_id` 全局唯一，创建后不可修改。明文密钥只在创建或轮换成功（含同键重放）时返回一次。
3. 名称 1–120 个字符。范围只能来自闭目录，空范围合法；未知范围拒绝。
4. 商户状态只允许 `ACTIVE` / `DISABLED`。启用要求当前为 `DISABLED`；停用要求当前为 `ACTIVE`。
5. 平台叠加层不得写入 `identity_shop_app`。非 `active` 叠加层阻止创建、轮换和启用；商户仍可停用已有应用。
6. 写命令必须带 8–128 位 `commandKey`。相同键相同摘要重放首次结果；相同键不同摘要拒绝。
7. 轮换、启停必须携带匹配的 `expectedVersion`。
8. 浏览器不得提交 `merchant_id`、明文密钥或旧 `appId`/`commercialId`。会话绑定店铺时，请求 `shopId` 必须与 claims 一致。
9. 范围字符串不是 Identity 角色权限，也不签发 Module Capability。Webhook 与应用授权仍未接入。
