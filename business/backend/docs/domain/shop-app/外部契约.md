# 店铺私有应用对外契约

Merch HTTP surface 使用会话中的 `merchant_id`，浏览器只提交 `shopId`：

- `GET /merch/identity/apps/shops`：列出当前商户未关闭店铺。会话绑定店铺时只返回该店。权限 `identity.app.read`。
- `GET /merch/identity/apps/scopes`：返回可勾选的范围目录。权限 `identity.app.read`。
- `GET /merch/identity/apps`：按店铺分页列出私有应用，可筛商户状态。响应附带该店 `apps` 平台叠加层，密钥只回尾号。权限 `identity.app.read`。
- `POST /merch/identity/apps`：创建应用并返回一次性明文密钥。权限 `identity.app.manage`。
- `POST /merch/identity/apps/{appId}/reset`：轮换密钥并返回一次性明文密钥。权限 `identity.app.manage`。
- `POST /merch/identity/apps/{appId}/enable`：启用已停用应用。权限 `identity.app.manage`。
- `POST /merch/identity/apps/{appId}/disable`：停用已启用应用。权限 `identity.app.manage`。

写契约要求 `commandKey`。启停和轮换还要求 `expectedVersion`。响应返回规范化应用、`replayed`，以及创建/轮换时的 `clientSecret`。Manifest Contribution `identity.merch.apps` 路由仍是 `/settings/apps`。

旧路径 `/commercial/settings/apps*` 不再提供。平台叠加层读写仍走总后台商户能力治理。
