# 店铺私有应用状态机

```text
（不存在）──创建──> ACTIVE
ACTIVE ──停用──> DISABLED
DISABLED ──启用──> ACTIVE
ACTIVE / DISABLED ──轮换密钥──> 同状态，密钥失效并换新
```

| 当前状态 | 命令 | 目标状态 | 前置条件 | 副作用 |
|---|---|---|---|---|
| 不存在 | 创建 | `ACTIVE` | 店铺未关闭；平台叠加层 `active` 或缺失；名称和范围合法 | 生成 `client_id` 与密钥；只存散列和尾号；命令账本保存明文供重放。 |
| `ACTIVE` | 停用 | `DISABLED` | 期望版本匹配 | 版本 +1；不改密钥。叠加层受限时仍允许。 |
| `DISABLED` | 启用 | `ACTIVE` | 期望版本匹配；叠加层允许 | 版本 +1。 |
| `ACTIVE` / `DISABLED` | 轮换密钥 | 不变 | 期望版本匹配；叠加层允许 | 生成新密钥，旧散列失效；版本 +1。 |
| 任意 | 删除 | 非法 | 不提供物理删除 | 商户用停用收敛泄露面。 |

相同 `commandKey` 重放始终返回第一次规范结果，创建/轮换重放仍返回当时明文密钥。并发启停或轮换同一行时，行锁和期望版本使一个成功、另一个冲突。
