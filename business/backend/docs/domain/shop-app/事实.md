# 店铺私有应用事实源

Identity shop capability 拥有商户为当前店铺签发的私有应用凭据。这不是公开应用市场，也不把密钥或 OAuth grant 复制到 Platform / Catalog / Trade。

## 旧系统到当前模型的逐项对照

| 旧表/接口字段 | 旧语义证据 | 当前字段 | 迁移规则 |
|---|---|---|---|
| `merchant_private_app` 主键 | 私有应用行 | `private_app_id` | 新表自增；不沿用旧主键 |
| `appid` + `commercial_id` | 旧运行时隔离键 | 非运行时 | 必须解析到 `merchant_id + shop_id`；claims 与表都不保存旧键 |
| `name` | 应用显示名，最长 120 | `name` | trim 后 1–120 个字符 |
| `client_id` | `app_` + 24 位 hex，全局唯一 | `client_id` | 服务端生成；创建后不可改 |
| `client_secret_hash` | SHA-256 hex；明文只在创建/轮换响应出现一次 | `client_secret_hash` | 继续单向散列；列表只回 `secret_hint` |
| `secret_hint` | 明文密钥尾 6 位 | `secret_hint` | 一对一 |
| `scopes` | 逗号分隔自由字符串，授权尚未接入 | `scopes` | 收敛为封闭目录；空值合法；存规范化逗号串 |
| `merchant_status` `active`/`disabled` | 商户启停 | `status` `ACTIVE`/`DISABLED` | 大小写对齐 Identity 其他状态 |
| 行上 `platform_status` | 旧表复制治理状态 | `identity_merchant_capability` `module=apps` | 禁止复制到应用行；缺行视为 `active` |
| 无版本 / 无命令键 | 覆盖写 | `version` + `commandKey` | 写命令可重试；启停和轮换校验期望版本 |
| `last_used_at` | 列存在但页面未使用 | 不迁 | 没有调用证据 |
| 应用授权 / Webhook | 旧页明确未接入 | 不迁 | 本菜单只迁凭据、范围字符串、轮换和启停 |

## 唯一事实源

- 私有应用：`identity_shop_app`，归属同一 `identity_shop` 行证明的 `merchant_id + shop_id`。
- 幂等结果：`identity_shop_app_command`。创建/轮换的一次性明文密钥只保存在该命令账本中，供同键重放，不进入列表接口。
- 平台叠加层：`identity_merchant_capability`（`module=apps`）。
- 不物理删除。关闭店铺后读写均视为范围不存在。

菜单可见性仍受订阅权益约束。默认套餐不含 `identity.app.read` / `identity.app.manage`；运营必须把权限加入对应套餐后，菜单和写接口才对商户员工开放。
