# 状态机

## 套餐目录

```text
创建 → ACTIVE
ACTIVE ⇄ DISABLED
ACTIVE|DISABLED → RETIRED
```

`RETIRED` 是终态。商户目录只展示 `ACTIVE`。

## 商户套餐指派

每个 `merchant_id` 至多一条当前指派。来源可以是总后台指派或商户购买开通。指派覆盖写当前档；过期时间 `NULL` 表示永久。

## 商户购买订单

```text
创建 → PENDING
PENDING → PAID      # Trade 已支付后幂等开通
PENDING → CANCELLED # 仅账单菜单；本页不提供取消
PAID、CANCELLED 终态
```

- `PENDING`：已快照套餐，等待 Trade 收款结果。
- `PAID`：订单已收款且订阅已按快照开通或续期。
- 响应丢失后用同一 `command_key` 重放首次结果，不重复开通。
