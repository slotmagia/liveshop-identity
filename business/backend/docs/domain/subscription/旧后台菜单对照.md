# 总后台「订阅管理」迁移对照

| 旧事实 / 行为 | 旧承载 | 目标承载 | 迁移规则 |
|---|---|---|---|
| 套餐角色 | `subscription_role` | `subscription_plan` | 字段逐项迁移；`price -> price_minor` 仅规范命名，不改变分单位。 |
| 套餐码 | `subscription_role.code` | `subscription_plan.code` | 稳定唯一，创建后不可修改。 |
| 永久套餐 | `duration_days=0` | `duration_days=0` | 语义不变。 |
| 启用 / 停用 | `status=1/0` | `ACTIVE/DISABLED` | 一对一状态规范化。 |
| 删除套餐 | 物理删角色和授权，商户悬空后回落默认 | `RETIRED` 终态 | 有意替换为可审计终态；商户套餐迁移时必须显式换档，不再依赖悬空外键回落。 |
| 默认套餐 | 多行布尔、事务清其它默认 | guard 行锁下唯一活动默认 | 保持最多一个默认并加强为不能无默认。 |
| 套餐授权 | `role_permission` | `subscription_plan_permission` | 只接收当前 Registry 活动权限码；旧资源码无可靠映射时不猜测。 |
| 权限资源 CRUD | `perm_resource` | Platform Registry Manifest | 当前订阅页面只读活动目录；定义随模块发布注册。 |
| API 自动目录 | `api_catalog` | Platform Registry operation | 当前订阅页面由权限目录显示模块、资源、动作；不复制路由事实。 |
| 验证器目录 | 进程内注册表 | 各业务 capability 不变量 | 不允许订阅页面编辑其他模块业务验证逻辑。 |
| 新建/编辑套餐 | `POST /console/subscription/roles`，不含权限字段 | 套餐 POST/PUT | 只写基本信息，不允许同时选择或覆盖权限。 |
| 权限配置入口 | 套餐列表行“权限”按钮 | 套餐列表行“权限配置”按钮 | 独立读取、编辑和保存完整策略。 |
| 权限配置接口 | `GET/POST /console/subscription/role-permissions` | `GET/PUT .../plans/{planID}/permissions` | 保持整组读取、整组覆盖语义；目标增加 command key 与 expected policy revision。 |
| 商品额度 | 旧 `api.product.create` 验证器的 `max_products` 配置 | `subscription_plan_quota(catalog.products)` | 属于权限策略配置，不进入新建/编辑套餐表单；必须显式正数或不限额。 |
| 商户订阅指派 | 商户管理页 `SubscriptionModal` | 后续迁移「商户管理」订阅交互 | 不重复塞进本菜单；应用套餐时再原子生成权限和额度 entitlement。 |

## 页面行为

- 菜单目录、菜单名和路由保持 `商城中台 → 订阅管理 → /subscription`。
- 套餐基本信息弹窗只支持套餐码、名称、等级、排序、价格、计价天数、状态、默认标记和说明。
- 每条套餐的“权限配置”按钮单独打开完整权限集合与商品额度策略；策略保存不修改套餐基本信息 version。
- 权限目录页签只读展示活动 Registry 权限码、模块、资源、动作和说明。
- 所有字符串由共享组件以 `textContent` 渲染；创建/编辑使用 Host 表单模态框。
