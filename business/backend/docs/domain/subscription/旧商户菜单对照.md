# 商户后台「订阅套餐」迁移对照

## 旧页面与接口证据

- 菜单：`menu.subscription`，路由 `/merchant/plans`。
- 旧前端：`woklive-merchant/src/views/business/subscription`。
- 旧接口：
  - `GET /commercial/subscription/plans`
  - `GET /commercial/entitlements`（当前档/到期/配额用量/菜单锁）
  - `GET /commercial/subscription/pay-methods`
  - `POST /commercial/subscription/orders`
  - `POST /commercial/subscription/orders/confirm`
  - `GET /commercial/subscription/orders/status`
- 旧购买：仅 `price > 0` 且（非当前档或限时当前档）显示购买/续费；免费档由总后台指派。
- 旧开通：`duration_days=0` 永久；同档未过期续费顺延；换档立即生效。

## 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `subscription_role.code` | `subscription_plan.code` | 稳定套餐码。 |
| `price` | `price_minor` | 仍是分。 |
| `duration_days=0` | `duration_days=0` | 永久。 |
| `is_current` / `is_default` | 由当前指派和套餐默认标记计算 | 不另存。 |
| 套餐 `menus[]`（perm_resource 菜单名） | 套餐权限集合的 Registry 权限名 | 不再复制菜单目录。 |
| 套餐 `quotas[]`（shop 等计数器） | `catalog.products` 额度上限 | 唯一有证据的 Catalog 计数器。 |
| 权益 `used/max` | 只返回 Identity 上限 | 用量由 Catalog 拥有，本页不猜测。 |
| `appid` + `merchant_id` + `uid` | `merchant_id` | 运行时隔离只用 `merchant_id + shop_id`。 |
| `channel_id` | `channelCode` | Trade 通道稳定码。 |
| `pending/paid/cancelled` | `PENDING/PAID/CANCELLED` | 状态规范化。 |
| 支付 payload / 钱包直扣 | Trade 收款结果 | Identity 只保存 `pay_no` 引用。 |
| 账单列表/取消 | `/merchant/billing` | 不并入本菜单；见 [旧商户账单菜单对照.md](./旧商户账单菜单对照.md)。 |

## 页面迁移结果

- 菜单目录、名称和 `/merchant/plans` 保持不变。
- 上卡展示可售套餐；当前档徽标、默认徽标、价格、周期、说明、商品额度、权限名、购买/续费。
- 下卡展示当前套餐、到期、额度上限和已开通权限。
- 购买使用 `hostFormModal()` 选择通道；无 Trade 收款通道时不能提交，也不生成假支付。
- 说明以 `textContent` 渲染，不把运营富文本当 HTML 解析。
- 无 `identity.subscription.read` 不显示菜单；无 `identity.subscription.purchase` 或非 Owner 隐藏购买。
