# 对外契约

Admin HTTP surface 提供订阅菜单专用契约：

- `GET /admin/identity/subscription/plans`：读取全部非退役套餐基本信息。
- `POST /admin/identity/subscription/plans`：用稳定 `commandKey` 创建套餐，`expectedVersion` 固定为 0。
- `PUT /admin/identity/subscription/plans/{planID}`：用稳定 `commandKey` 和 expected version 修改套餐。
- `POST /admin/identity/subscription/plans/{planID}/retire`：用稳定 `commandKey` 和 expected version 推进到退役终态。
- `GET /admin/identity/subscription/permissions`：读取 Platform Registry 活动权限目录投影，只读展示和套餐选择，不提供权限定义写接口。
- `GET /admin/identity/subscription/plans/{planID}/permissions`：读取某套餐的完整权限、商品额度和 policy revision。
- `PUT /admin/identity/subscription/plans/{planID}/permissions`：使用稳定 `commandKey` 和 expected policy revision 整组替换套餐策略。

全部接口要求 `identity.subscription.manage` Module Capability；写请求还必须通过当前授权修订校验。页面 contribution 的 `allowedRoutes` 只覆盖上述前缀。

Merch HTTP surface 提供订阅套餐页专用契约：

- `GET /merch/identity/subscription/plans`：当前商户可见的 `ACTIVE` 套餐卡片，含价格、周期、商品额度上限和权限名称。
- `GET /merch/identity/subscription`：当前套餐指派、到期、额度上限和已开通权限。
- `GET /merch/identity/subscription/pay-methods`：向 Trade 读取订阅收银通道；Trade 未发布收款契约时返回空列表。
- `POST /merch/identity/subscription/orders`：创建或复用 `PENDING` 购买订单并请求 Trade 收款。
- `GET /merch/identity/subscription/orders/{orderNo}`：查询本商户订单；若 Trade 已支付则幂等开通。
- `POST /merch/identity/subscription/orders/{orderNo}/confirm`：钱包直扣确认路径；成功即开通。
- `GET /merch/identity/subscription/orders`：分页列出本商户购买订单，不查询 Trade，也不开通。
- `POST /merch/identity/subscription/orders/{orderNo}/close`：把 `PENDING` 订单推进到 `CANCELLED`；仅 `MERCHANT_OWNER`。不请求 Trade 取消支付单。

读接口要求 `identity.subscription.read`；购买写接口要求 `identity.subscription.purchase`，且仅 `MERCHANT_OWNER` 可下单或关闭未支付订单。付款结果只来自 Trade；Identity 不编造二维码、跳转或余额扣减。账单页不得调用 `GET /merch/identity/subscription/orders/{orderNo}`。

`SubscriptionService` 仅允许显式受信任 workload 经 TLS 1.3 双向认证调用：

- `Check`：数据库就绪探针。
- `GetQuotaLimit`：读取一项明确生效的额度上限。
- `GetQuotaLimits`：在一个 MySQL repeatable-read 快照中按请求顺序读取多项额度。
- `GetMerchantPermissionEntitlementSnapshot`：只授予 Identity SPIFFE，读取一个商户的完整有序权限集合、revision、摘要与来源更新时间。

调用方应使用不超过 2 秒的 deadline。`FailedPrecondition` 表示没有明确生效的 entitlement；`Unavailable/Internal/DeadlineExceeded` 均属于结果未知，建品必须停止。响应的 `unlimited=true` 只能来自数据库中的显式不限额事实。

Catalog SPIFFE 只拥有 health/quota read；Identity SPIFFE 只拥有 health/permission-entitlement read。二者不能借同一证书跨读。
