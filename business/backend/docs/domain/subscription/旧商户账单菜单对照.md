# 商户后台「账单」迁移对照

## 旧页面与接口证据

- 菜单：账单，路由 `/merchant/billing`。
- 旧接口：
  - `GET /commercial/billing/list`
  - `POST /commercial/billing/cancel`
- 旧页面是订单列表加取消；详情接口存在，但本页不依赖详情。

## 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| 账单列表 | `GET /merch/identity/subscription/orders` | 仅本商户订单，不查询 Trade。 |
| 取消未支付 | `POST /merch/identity/subscription/orders/{orderNo}/close` | 方法词用封闭表 `close`，不是 `cancel`。 |
| `pending/paid/cancelled` | `PENDING/PAID/CANCELLED` | 状态规范化。 |
| 取消后可再下单 | generated `pending_slot` 离开 `PENDING` 后为 `NULL` | Identity 不 invent 支付取消。 |
| 支付详情 / 通道载荷 | 列表只展示 `payNo` 与 `channelCode` | 本页不调用 `GET .../orders/{orderNo}`，避免走开通路径。 |

## 页面迁移结果

- 菜单目录、名称和 `/merchant/billing` 保持不变。
- 查询卡只筛状态；分页在数据卡。
- 行内关闭仅 `PENDING`，且仅所有者 + `identity.subscription.purchase`。
- 关闭使用 `hostFormModal()` 确认；瞬时反馈用 `notify()`。
- 无 `identity.subscription.read` 不显示菜单。
