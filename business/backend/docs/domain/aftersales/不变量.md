# 商户售后工单不变量

1. 每条售后必须绑定同一 `identity_shop` 行证明的 `merchant_id + shop_id`；两个维度不得由浏览器拼接或互相替代。`app_id`/`commercial_id` 不是运行时标识。
2. 商户范围只来自 merch Module Session。请求不得携带 `merchantId`/`shopId`，也不得改查另一店铺。
3. `customer_subject` 为 1–128 且不含空白。它是 Identity 主体引用，不是旧 `uid` 运行时列。
4. `order_id > 0`。`payment_no` 最长 64。Identity 不校验 Trade 订单或支付行是否仍存在。
5. `type` 只能是 `REFUND_ONLY|RETURN_REFUND`。`REFUND_ONLY` 的 `return_status` 必须是 `NOT_REQUIRED`。`RETURN_REFUND` 只能是 `PENDING` 或 `RECEIVED`。
6. `requested_amount >= 1`。`amount` 为当前批准额，必须 `1 ≤ amount ≤ requested_amount`。
7. `reason` 为 1–255。`handle_note` 在 `PENDING` 时为空；审核后为 1–2000。
8. `status` 只能是 `PENDING|APPROVED|REJECTED|REFUNDED|CLOSED`。本切片 merch 审核只允许 `PENDING → APPROVED|REJECTED`。`REFUNDED`/`CLOSED` 不由本页写入。
9. 确认退货只允许 `RETURN_REFUND` 且 `return_status=PENDING`，并且工单已是 `APPROVED` 或 `REFUNDED`。本切片不要求 Trade 已退款完成。
10. 写命令必须带 8–128 的 `commandKey` 与当前 `expectedVersion`。相同 key 相同摘要重放同一结果；相同 key 不同摘要冲突。
11. 关闭或缺失店铺不能列出、读取、审核或确认退货。
12. 本切片不提供创建或物理删除 HTTP。Shop 申请、Trade 退款执行与 Catalog 回补不在本页。
