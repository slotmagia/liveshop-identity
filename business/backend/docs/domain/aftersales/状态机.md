# 商户售后工单状态机

```text
不存在 ──Shop 申请（非本页）──> PENDING
PENDING ──review APPROVED──> APPROVED
PENDING ──review REJECTED──> REJECTED
APPROVED / REFUNDED + RETURN_REFUND + return PENDING ──returns.create──> return RECEIVED
REFUNDED / CLOSED ──本页──> 不写入（留给后续 Trade 回写）
终态审核 ──同 commandKey──> 重放
CLOSED 店铺 ──列表/读取/写命令──> 范围不存在
```

| 当前状态 | 命令 | 目标状态 | 前置条件 | 副作用 |
|---|---|---|---|---|
| 任意未关闭店铺 | merch GET 列表/详情 | 不变 | Session 含 `merchant_id + shop_id`；`identity.aftersale.read` | 只读；空列表合法。 |
| 关闭店铺 | merch GET / review / returns | 非法 | 店铺 `CLOSED` 或缺失 | 返回不存在。 |
| `PENDING` | `review` + `APPROVED` | `APPROVED` | `identity.aftersale.manage`；版本匹配；说明 1–2000；金额 1–申请额 | 写入 `amount`、`handle_note`、`reviewed_at`，版本 +1。不调用 Trade。 |
| `PENDING` | `review` + `REJECTED` | `REJECTED` | 同上；金额保持申请额 | 同上。 |
| `APPROVED`/`REJECTED`/`REFUNDED`/`CLOSED` | `review` | 非法 | 非重放 | 冲突。 |
| `RETURN_REFUND` 且 `return_status=PENDING` 且状态 `APPROVED` 或 `REFUNDED` | `returns.create` | `return_status=RECEIVED` | 至少一行项目；版本匹配 | 行项目 `received_quantity=quantity`；写入 `received_at`；版本 +1。不改 Catalog。 |
| 其它退货组合 | `returns.create` | 非法 | 非重放 | 冲突。 |
| 任意 | 同 `commandKey` 同摘要 | 上次结果 | 命令账本命中 | `replayed=true`，不改行。 |
