# 店铺品类对外契约

Admin HTTP surface 使用 `identity.shop-category.manage` 权限：

- `GET /admin/identity/shop-categories`：列出全部非退役品类和实时引用店铺数。
- `POST /admin/identity/shop-categories`：创建品类，`expectedVersion` 必须为 `0`。
- `PUT /admin/identity/shop-categories/{categoryID}`：按期望版本编辑名称、图标、排序和状态；代码不可变。
- `POST /admin/identity/shop-categories/{categoryID}/enabled`：按期望版本启用或停用。
- `POST /admin/identity/shop-categories/{categoryID}/retire`：按期望版本推进到不可恢复的退役终态。

四项写契约均要求 `commandKey`。响应返回规范化品类、当前版本、引用店铺数和 `replayed` 标志。Manifest Contribution `identity.admin.shop-categories` 只开放 `/admin/identity/shop-categories` 前缀，不复用店铺只读权限。

商户建店可选目录由 `GET /merch/identity/shops/categories` 提供。创建店铺的同一事务必须读取 `ACTIVE` 品类并写入 `identity_shop.category_code`，不得从 Admin 页面缓存或 Catalog 商品分类推导。
