# 店铺品类事实源

- Identity 是店铺经营品类目录及店铺 `category_code` 引用的唯一事实源。
- 店铺经营品类描述店铺主营行业，不是 Catalog 拥有的商品分类树；两者不得共表或共用写接口。
- `identity_shop_category` 保存稳定代码、名称、Emoji 图标、排序、状态和版本。
- `identity_shop.category_code` 是可空的稳定引用。迁移无法从当前店铺事实推导旧品类，因此既有店铺保持 `NULL`，不得猜测回填。
- 总后台“商城中台 → 店铺品类 → /shop-category”维护目录；退役记录保留在数据库中但不进入管理列表和未来的新建店铺可选目录。
- `usedShopCount` 是从 `identity_shop.category_code` 实时计算的派生值，不是独立维护的业务事实。
