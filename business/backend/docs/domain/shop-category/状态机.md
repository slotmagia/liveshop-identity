# 店铺品类状态机

| 当前状态 | 命令 | 目标状态 | 前置条件 | 副作用 |
|---|---|---|---|---|
| 不存在 | 创建启用品类 | `ACTIVE` | 代码唯一；`expectedVersion=0` | 插入版本 `1` 的目录行并完成命令账本。 |
| 不存在 | 创建停用品类 | `DISABLED` | 代码唯一；`expectedVersion=0` | 插入版本 `1` 的目录行并完成命令账本。 |
| `ACTIVE` | 编辑元数据 | `ACTIVE` 或 `DISABLED` | 代码不变；期望版本匹配 | 更新名称、图标、排序、状态并推进版本。 |
| `DISABLED` | 编辑元数据 | `DISABLED` 或 `ACTIVE` | 代码不变；期望版本匹配 | 更新名称、图标、排序、状态并推进版本。 |
| `ACTIVE` | 停用 | `DISABLED` | 期望版本匹配 | 推进状态和版本；既有店铺引用不变。 |
| `DISABLED` | 启用 | `ACTIVE` | 期望版本匹配 | 推进状态和版本。 |
| `ACTIVE` / `DISABLED` | 退役 | `RETIRED` | 期望版本匹配 | 推进状态和版本；保留目录行及店铺引用。 |
| `RETIRED` | 任意编辑、启停或退役 | 非法 | 终态禁止变更 | 返回冲突，不产生业务写入或命令账本残留。 |

对已经处于目标启停状态的新命令，业务结果保持不变且不推进版本，但命令账本仍记录规范结果；相同命令键重放始终返回第一次结果。
