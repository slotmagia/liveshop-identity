# 总后台「店铺品类」迁移对照

## 旧页面与接口证据

- 页面入口：`woklive-admin/src/views/shop-category/index.tsx`。
- 表格字段：排序、图标、代码、名称、状态和操作。
- 页面交互：刷新、新增、编辑、点击状态启停、删除。
- 表单字段：`id/code/name/icon/sort/status`；代码和名称必填，图标为 Emoji。
- 旧 Admin 接口：
  - `GET /console/shop-category/list`
  - `POST /console/shop-category/upsert`
  - `POST /console/shop-category/enabled`
  - `POST /console/shop-category/delete`
- 旧商户侧消费者：`GET /commercial/shop/categories` 只读取启用品类，供建店表单下拉使用。
- 旧数据表：`shop_category`；`commercial_shop.category_code` 保存创建后不可改的代码引用。

## 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `id` | `category_id` | 自增技术主键，接口继续返回 `id`。 |
| `code` | `code` | 保持 2–32 位小写字母、数字和下划线；创建后不可修改。 |
| `name` | `name` | 去除首尾空白，最长 64 字符。 |
| `icon` | `icon` | 保留可选 Emoji，最长 16 字符。 |
| `sort` | `sort_order` | 非负整数，列表按排序和主键升序。 |
| `status=1/0` | `ACTIVE/DISABLED` | 显式状态枚举，启停要求期望版本。 |
| 物理删除 | `RETIRED` 终态 | 页面仍提供“退役”入口，但数据库保留引用目标和审计结果。 |
| 无版本字段 | `version` | 所有编辑、启停和退役都校验旧版本。 |
| 无幂等键 | `commandKey` | 所有写命令可安全重试并防止同键异载荷。 |
| 未展示引用情况 | `usedShopCount` | 从 Identity 店铺事实实时统计，帮助退役决策。 |

## 页面迁移结果

- 菜单目录、名称和 `/shop-category` 路由保持不变。
- 使用 Host 菜单说明卡和一个标准数据卡；刷新、新增位于数据卡工具栏，编辑、启停和退役位于表格行内。
- 新增、编辑和退役均使用 `hostFormModal()`，不创建 iframe 内第二套遮罩。
- 编辑时稳定代码只读；退役弹窗明确说明已引用店铺不会丢失历史引用。
- 页面不提供静态假数据，直接读取 Identity 权威接口。
