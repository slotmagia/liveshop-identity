# 店铺品类不变量

1. 品类代码全局唯一、区分大小写，并在创建后不可修改。
2. 品类状态只允许 `ACTIVE`、`DISABLED`、`RETIRED`。
3. `ACTIVE ↔ DISABLED` 可以双向转换；`ACTIVE/DISABLED → RETIRED`；`RETIRED` 是不可恢复终态。
4. 品类不做物理删除。已引用品类退役后，店铺的 `category_code` 仍保持原值。
5. 只有 `ACTIVE` 品类可供后续店铺创建选择；停用和退役不反向修改既有店铺。
6. 每次写入必须校验期望版本；并发命令最多一个从相同旧版本成功。
7. 每个可重试命令使用稳定 `commandKey`。相同键和相同请求返回原结果；相同键配不同请求必须冲突。
8. 业务写入、版本推进和命令结果记录必须在同一数据库事务提交或一起回滚。
9. Identity 不维护第二份 Catalog 商品分类，不向 Platform Registry 写业务目录数据。
