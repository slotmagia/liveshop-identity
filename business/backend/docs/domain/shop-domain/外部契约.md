# 店铺自定义域名对外契约

Merch HTTP surface 使用会话中的 `merchant_id`，浏览器只提交 `shopId` 和本页固定的 `scene`。`scene` 可选，仅允许 `LIVE` 或 `SHOP`；列表与创建省略或空值时默认 `LIVE`。写命令若携带 `scene`，必须与该行一致，否则视为不存在。

- `GET /merch/identity/domains/shops`：列出当前商户未关闭店铺。会话绑定店铺时只返回该店。权限 `identity.domain.read`。
- `GET /merch/identity/domains`：按店铺分页列出未删除的自定义域名，可筛状态与场景。响应附带该店 `domains` 平台叠加层和部署侧 CNAME 目标指令。权限 `identity.domain.read`。
- `POST /merch/identity/domains`：绑定自定义主机并返回 TXT 挑战。权限 `identity.domain.manage`。
- `POST /merch/identity/domains/{domainId}/test`：按 TXT 挑战校验 DNS。权限 `identity.domain.manage`。
- `POST /merch/identity/domains/{domainId}/activate`：把已验证域名设为该场景主域名。权限 `identity.domain.manage`。
- `DELETE /merch/identity/domains/{domainId}`：软删除。权限 `identity.domain.manage`。

写契约要求 `commandKey`。校验、设主、删除还要求 `expectedVersion`。响应返回规范化域名和 `replayed`。

CNAME 目标来自 Platform 边缘快照，不是 Identity 配置文件。创建时若主机等于 Platform 保留入口/CNAME 目标则拒绝。

Manifest Contribution：

- `identity.merch.live-domains` 路由仍是 `/live/domains`，页面固定提交 `LIVE`。
- `identity.merch.settings-domains` 路由仍是 `/settings/domains`，页面固定提交 `SHOP`。

两页共用同一组已发布 operation，不新增第二套 path 或 domain 名。旧路径 `/commercial/settings/domains*` 不再提供。证书签发和公网根域名仍走 Platform。
