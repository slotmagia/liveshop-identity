# 店铺自定义域名不变量

1. 域名行必须绑定同一 `identity_shop` 证明的 `merchant_id + shop_id`；关闭店铺不能读写。
2. 未删除行的 `host` 全局唯一。删除进入 `DELETED` 后释放唯一槽，允许再次绑定同一主机。
3. `scene` 只允许 `LIVE` 或 `SHOP`。直播域名页写入固定为 `LIVE`，设置域名页写入固定为 `SHOP`；请求不得靠浏览器扩大场景或在同一页切换场景。
4. 每店每场景最多一个未删除主域名。只有 `VERIFIED` 行可以 `activate` 为主域名。
5. 商户状态只允许 `PENDING` / `VERIFIED` / `FAILED` / `DELETED`。`test` 根据 TXT 记录是否包含挑战值在 `VERIFIED` 与 `FAILED` 之间收敛；不能从 `DELETED` 测回。
6. 平台叠加层不得写入 `identity_shop_domain`。非 `active` 叠加层阻止创建、校验和设为主域名；商户仍可删除已有域名。
7. 写命令必须带 8–128 位 `commandKey`。相同键相同摘要重放首次结果；相同键不同摘要拒绝。
8. 校验、设主、删除必须携带匹配的 `expectedVersion`。
9. 浏览器不得提交 `merchant_id` 或旧 `appId`/`commercialId`。各页只提交本页固定 `scene`，禁止场景选择器。会话绑定店铺时，请求 `shopId` 必须与 claims 一致。
10. CNAME 目标主机和证书不是 Identity 可写事实；Identity 不签发 TLS，也不把 Platform 根域名复制进本表。
