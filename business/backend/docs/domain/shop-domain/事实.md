# 店铺自定义域名事实源

Identity shop capability 拥有商户为店铺绑定的自定义域名、验证挑战和主域名标记。公网根域名、CNAME 目标主机和证书签发归 Platform；Live 只消费房间码，不保存第二份域名绑定。

## 旧系统到当前模型的逐项对照

| 旧表/接口字段 | 旧语义证据 | 当前字段 | 迁移规则 |
|---|---|---|---|
| `appid` + `commercial_id` | 旧运行时隔离键 | 非运行时 | 必须解析到 `merchant_id + shop_id` |
| `host` | 自定义主机名 | `host` | 小写 FQDN；全局对未删除行唯一 |
| `scene` | 添加时可提交；直播页与设置页共用接口 | `scene` `LIVE` / `SHOP` | 两页共用同一张表；直播页固定 `LIVE`，设置页固定 `SHOP`；浏览器不能自选扩大场景 |
| `verification_token` / `txt_*` | 添加后返回 TXT 挑战 | `txt_name` / `txt_value` | Identity 生成；列表对未删除行回显，供复制 DNS |
| `verification_status` / `status` / `dns_status` | 校验后更新 | `status` `PENDING`/`VERIFIED`/`FAILED`/`DELETED` | 大写枚举；`test` 命令根据 TXT 查找收敛 |
| `is_primary` | 设为主域名 | `is_primary` | 每店每场景最多一个未删除主域名；仅 `VERIFIED` 可激活 |
| `cname_target` | 添加/列表返回 | 响应指令，不入库 | 来自 Platform `GET /internal/v1/edge/snapshot` 的 `cnameTarget`；空则页面提示暂不可用 |
| `cert_status` / 证书申请 | 旧项存在 | 不迁 | Platform 拥有证书 |
| 行上 `platform_status` | 旧表复制治理状态 | `identity_merchant_capability` `module=domains` | 禁止复制到域名行；缺行视为 `active` |
| 无版本 / 无命令键 | 覆盖写 | `version` + `commandKey` | 写命令可重试 |
| `POST .../delete` 物理删除 | 旧删除 | `DELETED` | 不物理删除；释放 host 唯一槽后可再绑定同一主机 |

## 唯一事实源

- 自定义域名：`identity_shop_domain`，归属同一 `identity_shop` 行证明的 `merchant_id + shop_id`。
- 幂等结果：`identity_shop_domain_command`。
- 平台叠加层：`identity_merchant_capability`（`module=domains`）。
- 关闭店铺后读写均视为范围不存在。

直播菜单 `/live/domains`（`identity.merch.live-domains`）与设置菜单 `/settings/domains`（`identity.merch.settings-domains`）共用同一组 merch 命令。列表/创建省略 `scene` 时默认 `LIVE`；设置页始终提交 `SHOP`。

菜单可见性仍受订阅权益约束。默认套餐不含 `identity.domain.read` / `identity.domain.manage`；运营必须把权限加入对应套餐后，菜单和写接口才对商户员工开放。
