# 商户后台「直播域名」与「域名」迁移对照

## 旧页面与接口证据

- 菜单：`frontend.live.domains` 路由 `/live/domains`；设置菜单 `/settings/domains`。两页共用同一组旧接口。
- 旧前端：`woklive-merchant/src/views/business/live/domains`、`src/views/business/settings/domains`。
- 旧接口：
  - `GET /commercial/settings/domains`
  - `POST /commercial/settings/domains/add`（`host`、`scene`）
  - `POST /commercial/settings/domains/delete`（`id`）
  - `POST /commercial/settings/domains/primary`（`id`）
  - `POST /commercial/settings/domains/verify`（`id`）
- 旧隔离键是 `appid + commercial_id`。页面功能：添加/删除域名、发起验证、设为主域名。

## 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `appid + commercial_id` | `merchant_id + shop_id` | 运行时不再使用应用/商业隔离 ID。 |
| `host` | `host` | 小写 FQDN。 |
| `scene` | `LIVE`（直播页）/ `SHOP`（设置页） | 各页不让浏览器选场景。 |
| `verify` | `POST .../test` | 封闭方法词；TXT 命中即验证通过。 |
| `primary` | `POST .../activate` | 封闭方法词；仅已验证行。 |
| 物理删除 | `DELETED` | 释放 host 槽，保留命令账本。 |
| `cname_target` | 列表/创建响应指令 | 不入库；空表示 Platform 指令未配置。 |
| 证书状态 | 不迁 | Platform 拥有。 |

Contribution：`identity.merch.live-domains`（`/live/domains`）、`identity.merch.settings-domains`（`/settings/domains`）。读权限 `identity.domain.read`，写权限 `identity.domain.manage`。
