# 店铺风控记录事实源

Identity 的 risk capability 是商户店铺游客风险事件与当前风险快照的唯一事实源。菜单仍挂在商户后台「直播」目录，但 Live 只发布行为信号，不得保存或展示风险决策。总后台游客风控页仍是独立占位，不在本切片迁移。

## 旧系统到当前模型的逐项对照

| 旧表/接口字段 | 旧语义证据 | 当前字段 | 迁移规则 |
|---|---|---|---|
| 旧接口 `GET /commercial/live/risk-events` | 本店直播自动风控事件只读列表 | `GET /merch/identity/risk-events` | 不保留 `/commercial/*` 别名 |
| `visitor_id` | 游客标识 | `visitor_id` | trim 后 1–64，不含空白 |
| `nickname` | 事件发生时昵称快照 | `nickname` | 最长 64；可空 |
| `room_id` | 直播房间引用 | `room_id` | 非负整数；Identity 不建 Live 外键 |
| `reason` | 触发原因 | `reason` | trim 后 1–64 |
| `score_before` | 事件前分数 | `score_before` | 非负整数快照 |
| `score_after_decay` | 衰减后分数 | `score_after_decay` | 非负整数快照 |
| `score_delta` | 本次加减分 | `score_delta` | 整数，可负 |
| `score_after` | 事件后分数 | `score_after` | 非负整数快照 |
| `current_score` / `current_level` / `visitor_status` | 游客当前决策 | `identity_visitor_risk` | 列表 JOIN 当前快照，不把当前态写进历史事件行 |
| `page` / `per_page` | 分页 | `page` / `pageSize` | 默认 20，最大 100 |
| `appid` / `commercial_id` | 旧运行时隔离键 | 非运行时 | 只从 merch Module Session 读取 `merchant_id + shop_id` |

## 唯一事实源

- 不可变风险事件：`identity_risk_event`，归属同一 `identity_shop` 行证明的 `merchant_id + shop_id`。
- 游客当前风险快照：`identity_visitor_risk`，键是 `(merchant_id, shop_id, visitor_id)`。
- `room_id` 只是 Live 房间引用；本模块不读取 Live 库，也不展示房间标题。
- 本切片商户页只读。写入（Live 行为信号落地为事件与版本化决策）是后续 capability 消费者，不走本菜单 HTTP。
- 关闭店铺后列表视为范围不存在。事件行不做物理删除。
- 不保存 Platform telemetry 原始埋点。

商户后台菜单可见性仍受订阅权益约束。本地引导必须把 `identity.risk.read` 加入商户 entitlement，菜单和接口才会对商户员工开放。
