# 店铺风控记录对外契约

商户后台页面继续使用菜单路由 `/live/risk-events`，经 Gateway 调用以下唯一主契约。范围只来自 merch Module Session 的 `merchantId + shopId`。

| 方法与路径 | 用途 | 幂等 |
|---|---|---|
| `GET /merch/identity/risk-events` | 分页列出当前店铺风险事件，并 JOIN 游客当前分数/等级/状态 | safe |

操作要求 `identity.risk.read`。响应使用 camelCase：`id`、`visitorId`、`nickname`、`roomId`、`reason`、`scoreBefore`、`scoreAfterDecay`、`scoreDelta`、`scoreAfter`、`currentScore`、`currentLevel`、`visitorStatus`、`createdAt`。不返回 `merchantId`/`shopId`。

查询参数：`visitorId`、`roomId`、`reason`、`visitorStatus`、`page`、`pageSize`。`roomId` 为空或 0 表示不按房间过滤。

旧路径 `/commercial/live/risk-events` 不再提供。浏览器不得提交 `appId`/`commercialId` 或店铺 ID。本页不提供写接口。

## 事件

本切片不发布 Outbox。后续写入落地后，版本化风险决策再对 Trade 等消费者发布；Platform telemetry 原始事件不在本契约内。

## 菜单与权益

Manifest Contribution `identity.merch.risk-events` 只开放 `/merch/identity/risk-events` 的 GET。菜单是否出现取决于商户套餐是否包含 `identity.risk.read`，不会因为本地 Platform 引导账号而静默放行。
