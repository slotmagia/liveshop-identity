# 店铺风控记录事务与失败窗口

## 商户列表（本切片）

1. merch 逻辑从 Module Session 读取 `merchant_id + shop_id`；缺失即拒绝，不接受请求体或查询参数范围。
2. 规范化 `visitorId`、`roomId`、`reason`、`visitorStatus`、`page`、`pageSize`。
3. 开启 Identity MySQL 只读事务（`REPEATABLE READ`）。
4. 校验未关闭店铺行；关闭或缺失则失败。
5. 按店铺范围统计并分页读取 `identity_risk_event`，LEFT JOIN `identity_visitor_risk` 填充当前决策。
6. 提交只读事务。不写命令账本、不写 Outbox。

## 后续写入（非本页 HTTP）

Live 行为信号落地为风险事件时，必须在同一写事务内：锁定未关闭店铺、追加事件、条件更新游客快照版本。失败整笔回滚。商户列表不得承担该写入。

## 失败与恢复

- 店铺范围失败不返回其他店铺事件。
- 列表失败可安全重试；结果以提交后的只读快照为准。
- 进程在只读事务中崩溃：MySQL 回滚，客户端重新查询即可。
