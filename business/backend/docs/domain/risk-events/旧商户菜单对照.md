# 旧商户后台「风控记录」迁移对照

## 旧页面与接口证据

- 页面入口：`src/views/business/live/risk-events`。
- 菜单：直播 / 风控记录，路由 `/live/risk-events`。
- 旧接口：`GET /commercial/live/risk-events`。
- 旧查询：`visitor_id`、`room_id`、`reason`、`page`、`per_page`。
- 旧视图 `RiskEventView`：`id`、`visitor_id`、`nickname`、`room_id`、`reason`、`score_before`、`score_after_decay`、`score_delta`、`score_after`、`current_score`、`current_level`、`visitor_status`、`created_at`。
- 旧行为：只读；按本店自动风控事件分页。

## 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `appid` / `commercial_id` | `merchant_id + shop_id` | 只从 merch Module Session 读取；无法解析则阻塞。 |
| 列表字段 | 同名 camelCase JSON | 当前分/等级/状态来自游客快照 JOIN。 |
| `per_page` | `pageSize` | 默认 20，最大 100。 |
| 按房间、状态筛选 | `roomId`、`visitorStatus` | 房间是数字引用；状态使用封闭枚举。 |
| 页面结构 | Host 菜单说明卡 + 独立查询卡 + 数据卡表格 | 分页在数据卡 footer；失败用 `notify()`。 |

## 页面迁移结果

- 菜单目录、名称和 `/live/risk-events` 路由保持不变。
- Contribution 为 `identity.merch.risk-events`，权限 `identity.risk.read`。
- 页面不提供静态假数据，直接读取 Identity 权威接口。
- Live 后续通过行为信号写入本 capability；本页不调用 Live，也不迁移总后台 `/visitor-risk`。
