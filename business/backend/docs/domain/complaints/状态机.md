# 商户投诉管理状态机

```text
不存在 ──Shop 提交（非本页）──> OPEN
OPEN ──review ACCEPTED──> ACCEPTED
OPEN ──review REJECTED──> REJECTED
ACCEPTED / REJECTED ──终态──> 不可再审（同 commandKey 可重放）
CLOSED 店铺 ──列表/读取/审核──> 范围不存在
```

| 当前状态 | 命令 | 目标状态 | 前置条件 | 副作用 |
|---|---|---|---|---|
| 任意未关闭店铺 | merch GET 列表/详情 | 不变 | Session 含 `merchant_id + shop_id`；`identity.complaint.read` | 只读；空列表合法。 |
| 关闭店铺 | merch GET / review | 非法 | 店铺 `CLOSED` 或缺失 | 返回不存在。 |
| `OPEN` | `review` + `ACCEPTED` | `ACCEPTED` | `identity.complaint.manage`；版本匹配；处理说明 1–2000 | 写入 `handle_note`、`handled_at`，版本 +1。 |
| `OPEN` | `review` + `REJECTED` | `REJECTED` | 同上 | 同上。 |
| `ACCEPTED` / `REJECTED` | `review` | 非法 | 非重放 | 冲突。 |
| 任意 | 同 `commandKey` 同摘要 | 上次结果 | 命令账本命中 | `replayed=true`，不改行。 |
