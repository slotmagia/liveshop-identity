# 旧商户后台「投诉管理」迁移对照

## 旧页面与接口证据

- 页面入口：`src/views/business/complaints`。
- 菜单：商城管理 / 投诉管理，路由 `/complaints`。
- 旧接口：`GET /commercial/complaint/list`、`GET /commercial/complaint/detail/{id}`、`POST /commercial/complaint/handle`。
- 旧列表查询：`uid`、`status`、`page`、`perPage`。
- 旧处理：`id`、`status`、`handle_note`。
- 旧视图 `fulfillmentpb.Complaint`：`id`、`uid`、`target_type`、`target_id`、`reason_code`、`content`、`status`、`handle_note`、`created_at_ms`。
- 旧行为：筛选/分页；打开投诉；提交处理结果。Shop 提交不在本页。

## 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `appid` / `commercial_id` | `merchant_id + shop_id` | 只从 merch Module Session 读取。 |
| `uid` | `customerSubject` | Identity subject；列表筛选不再使用整数 uid。 |
| `handle` | `review` | 封闭方法词；目标状态只允许 `ACCEPTED`/`REJECTED`。 |
| `perPage` | `pageSize` | 默认 20，最大 100。 |
| 任意 `status` 字符串 | `OPEN`/`ACCEPTED`/`REJECTED` | 拒绝未登记状态。 |
| 页面结构 | Host 查询卡 + 数据卡表格 + `hostFormModal` 审核 | 分页在数据卡 footer；失败用 `notify()`。 |

## 页面迁移结果

- 菜单目录、名称和 `/complaints` 路由保持不变。
- Contribution 为 `identity.merch.complaints`。
- 页面不提供静态假数据；空列表合法。
- 不迁移 Shop 提交、原因目录或 Trade 退款。
