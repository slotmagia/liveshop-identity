# 商户投诉管理事务与失败窗口

## 商户列表与详情

1. merch 逻辑从 Module Session 读取 `merchant_id + shop_id`；缺失即拒绝。
2. 规范化筛选与分页。
3. 开启 Identity MySQL 只读事务（`REPEATABLE READ`）。
4. 校验未关闭店铺行；关闭或缺失则失败。
5. 按店铺范围统计并分页读取，或按 `complaint_id` 读取单行。
6. 提交只读事务。不写命令账本、不写 Outbox。

## 商户审核

1. 规范化 `commandKey`、目标状态、处理说明与 `expectedVersion`。
2. 开启写事务。插入命令账本行；主键冲突则按摘要决定重放或幂等冲突。
3. 锁定未关闭店铺与投诉行。
4. 版本不匹配、非 `OPEN`、或目标状态非法则失败并回滚。
5. 更新状态、处理说明、`handled_at` 与版本；回写命令回执后提交。
6. 失败整笔回滚。不向 Trade 发退款，不改库存。

## 失败与恢复

- 店铺范围失败不返回其他店铺投诉。
- 列表失败可安全重试。
- 审核失败后客户端用新 `commandKey` 或原 key 重试；原 key 且摘要相同则重放。
