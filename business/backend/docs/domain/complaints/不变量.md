# 商户投诉管理不变量

1. 每条投诉必须绑定同一 `identity_shop` 行证明的 `merchant_id + shop_id`；两个维度不得由浏览器拼接或互相替代。`app_id`/`commercial_id` 不是运行时标识。
2. 商户范围只来自 merch Module Session。请求不得携带 `merchantId`/`shopId`，也不得改查另一店铺。
3. `customer_subject` 为 1–128 且不含空白。它是 Identity 主体引用，不是旧 `uid` 运行时列。
4. `target_type` 只能是 `ORDER|AFTERSALE|LIVE|PRODUCT|OTHER`。`target_id >= 0`。Identity 不校验对方行是否仍存在。
5. `reason_code` 为 1–64。`content` 为 1–4000。`handle_note` 在 `OPEN` 时为空；审核后为 1–2000。
6. `status` 只能是 `OPEN|ACCEPTED|REJECTED`。`OPEN` 只能转入 `ACCEPTED` 或 `REJECTED`；终态不可再审，除非同一 `commandKey` 重放。
7. 写命令必须带 8–128 的 `commandKey` 与当前 `expectedVersion`。相同 key 相同摘要重放同一结果；相同 key 不同摘要冲突。
8. 关闭或缺失店铺不能列出、读取或审核投诉。
9. 本切片不提供创建或物理删除 HTTP。Shop 提交与 Trade 退款命令不在本页。
