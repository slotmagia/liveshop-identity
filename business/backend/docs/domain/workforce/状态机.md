# 商户员工与主播状态机

主体与成员成对转换，详见模块 [`状态机.md`](../状态机.md) 的 Workforce 段。

```text
（不存在）──创建──> ACTIVE / ACTIVE
ACTIVE / ACTIVE ──停用──> DISABLED / SUSPENDED
DISABLED / SUSPENDED ──启用──> ACTIVE / ACTIVE
ACTIVE|SUSPENDED ──撤销成员──> REVOKED（本页不提供）
```

| 当前状态 | 命令 | 目标状态 | 前置条件 | 副作用 |
|---|---|---|---|---|
| 不存在 | 创建 | `ACTIVE/ACTIVE` | Owner；至少一店；非空活动角色 | 原子写入主体、凭据、成员、店铺、grant；Outbox `identity.workforce.changed` |
| `ACTIVE/ACTIVE` | 停用 | `DISABLED/SUSPENDED` | 两个期望版本匹配 | 撤销会话；授权域 revision +1 |
| `DISABLED/SUSPENDED` | 启用 | `ACTIVE/ACTIVE` | 两个期望版本匹配 | 不恢复已撤销会话 |
| 任意可编辑 | 编辑 | 状态不变 | 两个期望版本匹配；店铺/角色合法 | 更新显示名；替换店铺与 grant；范围或角色变化则 access_version +1 并撤会话 |
| 任意 | 重置密码 | 状态不变 | 凭据期望版本匹配 | 写新散列并撤销会话 |
| 任意 | 物理删除 | 非法 | 不提供 | 用停用替代旧 `staff/delete` |

`REVOKED` 是成员终态，列表默认不展示。旧页删除员工在目标实现中映射为停用。
