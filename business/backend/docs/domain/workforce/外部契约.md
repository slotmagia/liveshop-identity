# 商户员工与主播对外契约

Merch HTTP surface 使用会话中的 `merchant_id` 与 `organization_id`：

- `GET /merch/identity/members/options`：当前商户可分配店铺、活动角色和组织单元。权限 `identity.staff.manage`。
- `GET /merch/identity/members`：分页列出 STAFF/ANCHOR，可按关键字、岗位、主体状态、店铺过滤。权限 `identity.staff.manage`。
- `GET /merch/identity/members/{subject}`：读取一名员工或主播。权限 `identity.staff.manage`。
- `POST /merch/identity/members`：创建员工或主播并授予初始角色。权限 `identity.staff.manage`。
- `PUT /merch/identity/members/{subject}`：更新显示名、店铺范围和角色。权限 `identity.staff.manage`。
- `POST /merch/identity/members/{subject}/enable` 与 `/disable`：启停。权限 `identity.staff.manage`。
- `POST /merch/identity/members/{subject}/credentials/{credentialId}/reset`：重置密码。权限 `identity.staff.manage`。
- `GET /merch/identity/members/{subject}/sessions`、`POST .../revoke`、`POST .../revoke-all`：会话。权限 `identity.session.manage`。

写契约要求 `idempotencyKey` 与 `operationId`。启停和编辑还要求 `expectedIdentityVersion` 与 `expectedAccessVersion`。重置密码要求 `expectedCredentialVersion`。逻辑层再次校验 `MERCHANT_OWNER`。

Manifest Contribution `identity.merch.users` 路由仍是 `/merchant/users`。角色定义页面仍是 `/merchant/roles`。旧路径 `/commercial/staff/*` 不再提供。
