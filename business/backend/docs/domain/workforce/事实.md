# 商户员工与主播事实源

Identity workforce 拥有商户组织内的员工、主播、店铺访问范围和初始角色授予。商户后台「用户管理」管理这些成员；角色定义仍在「角色管理」。所有者成员不进入本页命令目标。

## 旧系统到当前模型的逐项对照

| 旧表/接口字段 | 旧语义证据 | 当前字段 | 迁移规则 |
|---|---|---|---|
| `identity_staff` / `staff_id` | 商户员工主键 | `identity_workforce_member.member_id` | 新成员用 `member_id`；旧 `staff_id` 只作 `legacy_staff_id` |
| `account` | 登录账号 | `identity_credential.normalized_identifier` | 创建后不可改；命名空间员工 `GLOBAL`、主播 `SHOP` |
| `name` | 显示名 | `identity_subject.display_name` | trim 后必填 |
| `role_code` | 单个商户角色 | `identity_subject_grant.role_id[]` | 创建/编辑必须非空；只引用当前商户活动角色且权限 ⊆ 权益 |
| `shop_ids` | 可访问店铺 | `identity_member_shop` | 运行时范围是 `merchant_id + shop_id`；员工 `OPERATE` 可多店且至少一店；主播 `ANCHOR` 恰好一店 |
| `status` 整型启停 | 员工可用/停用 | 主体 `ACTIVE/DISABLED` 与成员 `ACTIVE/SUSPENDED` 成对转换 | 不迁物理删除；停用撤销会话 |
| `appid` / `commercial_id` | 旧隔离键 | 非运行时 | claims 与表都不保存旧键 |
| 角色 CRUD | 旧页与用户管理共用 staff API | `/merchant/roles` | 本页只分配已有角色，不创建角色 |

## 唯一事实源

- 主体与显示名：`identity_subject`
- 成员岗位：`identity_workforce_member`（`STAFF` / `ANCHOR`）
- 店铺范围：`identity_member_shop`
- 组织单元：`identity_organization_membership`（可空）
- 角色授予：`identity_subject_grant`
- 登录凭据：`identity_credential`
- 幂等结果：`identity_idempotency`（`provision_member` / `update_member` / 启停与重置）
- 会话：`identity_session`、`identity_refresh_token`

菜单可见性受 `identity.staff.manage` 约束。写命令仍校验 `MERCHANT_OWNER`；误授管理权限也不能让员工管理员工。
