# 商户后台「用户管理」迁移对照

## 旧页面与接口证据

- 菜单：`menu.merchant_users`，路由 `/merchant/users`。
- 旧前端：`woklive-merchant/src/views/business/staff`。
- 旧交互：创建/编辑/删除员工；重置密码；分配角色和店铺。
- 旧接口：`GET/POST /commercial/staff/*`。角色 CRUD 与本页共用 API 文件，目标拆到 `/merchant/roles`。

## 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| 员工列表无分页 | 分页列表 + 查询卡 | 遵守后台 UI 规范；分页不进搜索表单 |
| `account` / `name` / `role_code` / `shop_ids` | 账号、显示名、`roleIds`、`shopIds` | 账号创建后只读；角色可多选但必须非空 |
| 整型 `status` | `ACTIVE` / `DISABLED` | 列表展示主体状态 |
| `POST /staff/delete` | `POST .../disable` | 停用为可逆收敛；不物理删除 |
| 逗号录入角色和店铺 | `checkbox-tree` | 禁止手工填 ID |
| 角色 upsert/delete | `/merchant/roles` | 本页只读取可分配角色 |

## 页面迁移结果

- 菜单目录仍为「商户中心」，菜单仍为「用户管理」，路由仍为 `/merchant/users`。
- 占位 `identity.placeholder.merch.merchant-users` 替换为 `identity.merch.users`。
- 账号总览 `/merchant` 是只读身份摘要（`GET /merch/identity/account`），不再创建组织单元或启停员工；人员命令只在本页。

## 本轮完成

- Contribution `identity.merch.users` 使用查询卡 + 数据卡 + 底部分页；店铺和角色用 `checkbox-tree`。
- 创建走 `POST /merch/identity/members`；编辑走 `PUT /merch/identity/members/{subject}`。旧物理删除映射为停用。
- 列表只返回当前商户未撤销的 `STAFF` / `ANCHOR`，不展示所有者。
- 写命令仍失败关闭非 `MERCHANT_OWNER` 调用方；Gateway 权限不足同样拒绝。
