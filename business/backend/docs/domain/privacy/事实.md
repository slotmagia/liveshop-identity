# 店铺客户隐私事实源

Identity 的 shop capability 是商户可编辑的店铺隐私文档唯一事实源。总后台「商户能力治理」只维护 `module=privacy` 的平台叠加层，不得把叠加层状态写进隐私表。

## 旧系统到当前模型的逐项对照

| 旧表/接口字段 | 旧语义证据 | 当前字段 | 迁移规则 |
|---|---|---|---|
| `shop_privacy_setting` 主键 | 店铺隐私行 | `privacy_id` | 新表自增；不沿用旧主键 |
| `appid` + `commercial_id` | 旧运行时隔离键 | 非运行时 | 必须解析到 `merchant_id + shop_id`；claims 与表都不保存旧键 |
| `collect_consent` | 结账前收集隐私同意，缺省 `true` | `collect_consent` | 一对一布尔 |
| `marketing_consent` | 独立营销同意，缺省 `false` | `marketing_consent` | 一对一布尔 |
| `cookie_banner` | Cookie 提示，缺省 `true` | `cookie_banner` | 一对一布尔 |
| `data_retention_days` | 1–3650，缺省 365 | `data_retention_days` | 同一范围与缺省 |
| `contact_email` | 隐私联系人邮箱 | `contact_email` | trim 后小写；空值合法；非空必须是邮箱 |
| 无版本 | 覆盖写 | `version` | 首次保存为 `1`；后续写校验 `expectedVersion` |
| 无幂等键 | `POST` 覆盖 | `commandKey` | 8–128 字符；同键同摘要重放，同键异载荷冲突 |
| `platform_status` 展示 | 旧页从治理叠加层读取 | `identity_merchant_capability` | 只读投影到 merch 响应；禁止复制到 `identity_shop_privacy` |

## 唯一事实源

- 店铺隐私文档：`identity_shop_privacy`，按 `shop_id` 唯一，归属同一 `identity_shop` 行证明的 `merchant_id + shop_id`。
- 幂等结果：`identity_shop_privacy_command`。
- 平台叠加层：`identity_merchant_capability`（`module=privacy`）；未干预时视为 `active`，商户页可编辑。
- 缺行不插入：GET 返回内存默认值（收集同意开、营销同意关、Cookie 提示开、保留 365 天、邮箱空、`version=0`）。首次 PUT 且 `expectedVersion=0` 才插入版本 `1`。
- 不物理删除。关闭店铺后读写均视为范围不存在。

商户后台菜单可见性仍受订阅权益约束。默认套餐不含 `identity.privacy.manage`；运营必须把该权限加入对应套餐后，菜单和接口才会对商户员工开放。
