# 店铺客户隐私不变量

1. 每份隐私文档必须绑定同一 `identity_shop` 行证明的 `merchant_id + shop_id`；两个维度不得由浏览器拼接或互相替代。`app_id`/`commercial_id` 不是运行时标识。
2. 一个店铺最多一份隐私文档；键是 `shop_id`。
3. 未持久化时只允许返回默认值：`collectConsent=true`、`marketingConsent=false`、`cookieBanner=true`、`dataRetentionDays=365`、`contactEmail=""`、`version=0`、`id=0`。
4. `dataRetentionDays` 必须是 1–3650 的整数。`contactEmail` 为空或规范化后的合法邮箱，最长 254。
5. 首次写入 `expectedVersion` 必须为 `0`；已存在行必须匹配当前版本。并发命令最多一个从相同旧版本成功。
6. 同一 `commandKey` 重放返回第一次已经提交的结果；用不同请求复用该 key 必须冲突。
7. 平台叠加层 `restricted`/`suspended` 时禁止保存；叠加层状态不得写入 `identity_shop_privacy`。
8. 关闭店铺不能读取或保存隐私文档。隐私行不做物理删除。
9. 权威写入与 `identity.shop.privacy.changed` Outbox 必须在同一事务提交或一起回滚。
