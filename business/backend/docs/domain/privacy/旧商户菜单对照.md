# 旧商户后台「客户隐私」迁移对照

## 旧页面与接口证据

- 页面入口：`woklive-merchant/src/views/business/settings/module.tsx` 的 `PrivacyPage`。
- 菜单：设置 / 客户隐私，路由 `/settings/privacy`。
- 旧接口：`GET/POST /commercial/settings/privacy`。
- 旧字段：`collect_consent`、`marketing_consent`、`cookie_banner`、`data_retention_days`、`contact_email`。
- 缺行默认：收集同意开、Cookie 提示开、保留 365 天、营销同意关。
- 保存拦截：平台叠加层 `platform_status != "active"`。
- 旧表：`shop_privacy_setting`，键为 `appid + commercial_id`。
- 旧 UI：三个勾选、保留天数、联系邮箱，以及只读 `GovernanceBadge`。

## 字段映射

| 旧字段 / 行为 | 目标字段 / 行为 | 迁移规则 |
|---|---|---|
| `appid` / `commercial_id` | `merchant_id + shop_id` | 只从 merch Module Session 读取；无法解析则阻塞。 |
| 三个同意开关与天数、邮箱 | 同名 camelCase JSON | 校验规则保持 1–3650 与可选邮箱。 |
| 缺行默认值 | GET 内存默认，`version=0` | 不预先插行。 |
| `POST` 覆盖写 | `PUT` + `commandKey` + `expectedVersion` | 首次保存 `expectedVersion=0`。 |
| `platform_status` 展示与禁写 | merch 逻辑读取 `merchant_governance` `module=privacy` | 不写入 `identity_shop_privacy`。 |
| 页面结构 | Host 菜单说明卡 + 一个数据卡 | 刷新/保存在数据卡工具栏；表单内联，不使用 `hostOverlay()`。 |

## 页面迁移结果

- 菜单目录、名称和 `/settings/privacy` 路由保持不变。
- Contribution 为 `identity.merch.privacy`，权限 `identity.privacy.manage`。
- 页面不提供静态假数据，直接读取 Identity 权威接口。
- Live analytics 后续通过 `identity.shop.privacy.changed` 遵守同意快照，不在本页复制追踪事实。
