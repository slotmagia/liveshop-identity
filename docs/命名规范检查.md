# Identity 命名规范检查

本模块对外名字空间的检查入口。权威是本仓库 [`开发规范.md`](./开发规范.md) 第 6 章，不是模块外文档。

| 用途 | 文档 |
|---|---|
| 人工 / Agent 评审 | [命名规范检查提示词.md](./命名规范检查提示词.md) |

改 `business/module.json`、`g.Meta`、contribution、前端 `api.request` 之后，先按检查提示词跑一遍本模块。工具落地后执行：

```powershell
./business/backend/tools/verify-naming.ps1
```

`verify-fast.ps1` 必须在工具落地后调用它。未落地前不要做空壳脚本冒充通过。

## 范围

| 项 | 值 |
|---|---|
| module | `identity` |
| Manifest | `business/module.json` |
| HTTP prefix | `/admin/identity` · `/merch/identity` · `/shop/identity` · `/live/identity` |
| g.Meta | `business/backend/internal/identity/application/**/api/**/*.go` |
| 前端 | `business/frontend-admin/src` · `frontend-merch/src` · `frontend-shop/src` · `frontend-live/src` |

登记 domain：`health` `users` `members` `organization-units` `directory` `account` `profile` `authorization` `subscription` `merchants` `shops` `shop-categories` `customer-accounts` `merchant-governance` `privacy` `policies` `apps` `risk-events`。

权限码不含 surface。客服账号用 `identity.customer-account.*`，不要 `customer-service`。治理 API 用 `/admin/identity/merchant-governance`；页面 route `/settings-governance` 可以保留。

`identity.admin.directory.get` 是合法单例 API，不必挂到用户页。
